# ドア製品の階層構造

2026年9月17日。尼寺康泰。

玄関の仕事を、扉から人まで順に分ける。並びは下から上へ、物から人へ。AppleとGoogleとAmazonが玄関に入ってきた後の姿である。

## 一枚の表

| 層 | 残る者 | 経済の形 |
|---|---|---|
| ドア製造 | ドアメーカー。電子錠を埋め込む開口と、扉の中の通線路と、その等級を持つ | 防火認定と等級が堀。数は着工ではなく、建っている戸数 |
| 電子錠 | 競争で少数の優良な会社が残る。電動部は基準錠として買う物になる。認定や物理が要件の特殊な錠は残る | 汎用は値段が下がり続ける。特殊は認定で少数が高い利幅で残る |
| コントローラ | 扉側の専用コントローラ。火災と停電と避難の判断、監査の記録、二人同時と強要、通線路の自己診断、複数の入力の組み合わせを扉の中で持つ。ローカルだけで完全に動く。仕様は公開、作り方は各社 | SIerが独自の制御盤で握っていた席。公開の仕様に吸収され、独自の値段は消える。工夫の差は扉の中に残る |
| リーダー(読取機)= ドアホン | Apple、Google、Amazon。顔とNFCとUWBと声を一台で読む。消防連動や過酷環境が要件の特殊なリーダーは残る | 汎用は本体を一回売り、囲い込みは月額の映像。特殊は認定と物理で残る |
| スマートフォン | Apple、Google。財布の鍵と、本人の証拠 | 鍵に課金しない。囲い込みは本体 |
| 周辺機 | スピーカー、火災報知、センサー、室内カメラ。各社 | 買う物。足りない機能は一台足す |
| 機器同士の言葉 | 公開規格。Aliro、OSDP、ONVIF。そして扉のAPI(公開の仕様)。Matterは周辺機を受ける口の一つ | 無料。誰も所有しない |
| 鍵の発行 | 発行者。誰に鍵を出し、いつ失効させ、その人が本人かを判定して記録する | **利益が出る。** 一戸あたり月額、限界費用ゼロ |
| 機器と業務のつなぎ | 機器の出来事を、予約、名簿、鍵の台帳、暦に結ぶ | **利益が出る。** 汎用のSaaSにできない |
| 業務システム | 予約、名簿、会計、報告 | 無料に向かう。作らずに配る |
| 本人とAI社員 | 経営者本人。判定はAI社員、迷う一件だけ本人が見る | 外の人は既定でゼロ |

## 表の読み方

ドア製造から周辺機までは買う物である。機器同士の言葉は無料の規格で、誰の物でもない。利益が出るのは鍵の発行と、機器と業務のつなぎの二つだけで、業務システムは無料で配り、いちばん上に本人が一人いる。

## コントローラの層

コントローラは、SIerの独自の制御盤の中に隠れていた層である。入退室の一式で仕様と価格と保守を握っていたのは、錠でも扉でも読取機でもなく制御盤であった。読取機の側はAliroが公開の言葉にし、残ったのは火災と停電の判断、監査、二人同時、建物との連動である。

この層はローカルだけで完全に動く。網が無くても開いて閉まって記録する。だから物理鍵を無くせて、電子錠は追加ではなく基準錠になる。外のシリンダーが消え、開口の規格が一つになる。これはドアメーカーにしかできない変更である。

この層は、カメラとマイクとセンサーとAliroを扉の中で一つにする。線が物理的に集まる場所が扉だからである。ドアメーカーが利用者に提供する機能は、手ぶらで入れる、鍵を落としても他人は入れない、後ろから付いてきた人がいれば知らせる、脅されて開けたときは黙って知らせる、大事な部屋は二人で開ける、荷物の人は声で用件を言えば通す、家族や客ごとに開け方を選べる、である。

## 三社が競う場所

Apple、Google、Amazonが競うのはリーダーとスマートフォンと周辺機で、汎用の領域である。だからそれ以外は残る。読取機は作らない。

## 立つ場所

扉メーカーは、扉の製造と、扉側のコントローラに立つ。公開の仕様に入居し、その中で工夫する。

aiseedは、鍵の発行と、機器と業務のつなぎに立つ。そして扉コントローラの仕様と参照実装を公開する。仕様は利益の層ではなく、利益の層が入居できる扉を増やすための無料の紙である。
