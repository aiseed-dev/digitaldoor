# Aliro

2026年9月17日。尼寺康泰。

## 何か

スマートフォンが本人の証明として使えるようになる仕組みである。スマートフォンと読取機の間の相互認証を決める。NFCとBLEとUWBの三つの経路がある。2026年2月に1.0が出た。AppleとGoogleとSamsungと錠メーカーが入っている。

読取機から後ろは範囲の外だと、自分で決めている。扉に何かを命じない。

## 採る理由

検証が扉の中で終わる。網が切れても、スマートフォンと扉の二者で開く。

物理鍵を無くすには、代わりが一本では足りない。Aliroはその代わりを何本にも増やす。

- 経路が三つ。一つが不調でも別の経路で通る。
- 端末が複数。スマートフォンと時計に同じ鍵が入る。
- 電池切れに耐える。iPhoneは電源が落ちた後も数時間、財布の鍵をNFCで使える。
- 発行者が複数でも、同じ扉が受ける。経営者の鍵、管理の鍵、点検の人の鍵を別々に出せる。

これに、Aliroの外のローカルな経路を重ねる。受付端末の顔とPIN、読取機を二台三台置くこと、非常手段。どの経路も網に頼らない。網に頼る経路は何本足しても多重化にならない。

## 壁

財布に鍵を入れるには、AppleとGoogleの財布との契約が要る。読取機の側は自由でも、発行の側はそこを通る。これは鍵の発行者の層の参入壁であり、Aliroの値打ちを減らすものではない。

## 将来

カメラとマイクとセンサーとAliroが扉の中で連動する。組み合わせの判断は読む側ではなく扉の側が持つ。ここはドアメーカーの仕事である。
