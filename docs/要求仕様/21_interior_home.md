## 1. 業務用との違い

| 観点 | 業務用室内扉 | 家庭用室内扉 |
| --- | --- | --- |
| 相手 | 建物内の利用者 | 家族と来客。侵入者は玄関で止める前提 |
| 電子錠の要否 | 部屋の利用管理のため多くの扉に付く | 原則付けない。付けるのは勝手口・物置・ガレージ・特定の部屋（薬や貴重品、見守り）に限る |
| 主な価値 | 予約と権限、記録 | 見守り（開閉の検知）、締め忘れの防止、家族ごとの鍵 |
| 非常手段 | 管理者が壊さずに入る（2 つ以上） | 内側からは常に開き、外からは家庭用の非常解錠（コイン・ピン）または家族の鍵 |
| 通線 | 方式 A は通線 | 通線しない。電池 |
| 認定 | 不要 | 不要 |

## 2. 方針

| 項目 | 方針 |
| --- | --- |
| 機構 | 既存の室内錠（空錠、間仕切錠、表示錠）のまま。電子化する扉は Matter Door Lock 認証品の後付け（サムターン駆動型または電池式のクラッチ式既製品）。ドア製造者の埋込型（A2）は要求しない |
| 電子部 | Matter Door Lock 認証品（Thread）。Aliro は任意。電池運用、残量報告 |
| センサー | 見守り・締め忘れは Matter Contact Sensor（開閉）で足りる。錠を付けずにセンサーだけの扉を認める |
| ゲートウェイ | 個別住宅の玄関と同じミニ PC（親）。住戸内は Thread が届く範囲で追加のボーダールーターは原則不要 |
| 権限 | 家族の鍵（期限なし）、来客・業者の一時鍵（玄関と同じ仕組み）。二人同時などは要求しない |
| 監査ログ | Matter のイベントで足りる。ハッシュ連鎖は要求しない |

## 3. 要求（骨子）

| ID | 要求 |
| --- | --- |
| R-IH-01 | 内側からは常に機械的に開ける**こと**。子どもや高齢者が閉じ込められない構造（外からの非常解錠を持つ） |
| R-IH-02 | 電子錠を付ける扉は Matter Door Lock 認証品で**あること**。付けない扉は機械錠のままでよい |
| R-IH-03 | 電池残量を報告し、残量低下から最低 30 日は動作**すること**。電池切れ時は機械キーまたは家庭用の非常解錠で開く |
| R-IH-04 | 開閉の検知だけが目的の扉は、錠を付けずに Matter Contact Sensor で済ませてよい**こと** |
| R-IH-05 | 家族の鍵と一時鍵は玄関（10_entrance_house.md）と同じ資格情報の仕組みで発行・失効できる**こと** |
| R-IH-06 | 見守りの通知（一定時間開閉がない、夜間の開扉）は管理ソフトの設定で行い、常時の映像・音声を前提にしない**こと** |
