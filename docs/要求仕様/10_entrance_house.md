## 1. 用途と運用シナリオ

製造者が代替案を検討できるよう、想定する使われ方を先に示す。

### 1.1 想定用途

| 用途 | 特徴 |
| --- | --- |
| 個別住宅（居住中） | 家族の鍵はウォレット、来客・業者は一時鍵。停電・通信断でも家族が入れること |
| 空き家・管理物件 | 無人。遠隔で一時的な入室許可を出す。停電・通信断が長期間続くことがある |

### 1.2 入退室の経路

錠は次の**どれか一つが生きていれば**開くこと（経路の冗長性）。

| 経路 | 手段 | 錠側で必要なもの |
| --- | --- | --- |
| A. ゲートウェイ経由 | ミニ PC が有線または無線で錠に指示 | Ethernet / 多芯線 / 自前 BLE / Matter のいずれか |
| B. スマホ直接 | Aliro（NFC タップ、BLE） | 錠内で鍵を検証。ネット・ゲートウェイ不要 |
| C. 内側から | 機械的なハンドル操作 | 電気不要 |
| D. 停電時の外側 | 製造者提案（シリンダー、非常給電パッド、電池バックアップ） | 第 5 章 |

### 1.3 困ること（設計判断の優先順位）

1. 内側から出られない（人命。最優先で回避）
2. 外から勝手に開く（防犯）
3. 停電・通信断で入れない（運用）
4. 半ドアのまま「施錠済み」と表示される（誤報）

## 2. 状態モデル

錠は次の 3 軸の状態を持ち、それぞれを独立に検出・報告すること。

### 2.1 扉位置（センサー）

`open` / `half`（半ドア）/ `closed`（2 段目まで噛んだ）

### 2.2 掛かり（センサー）

`unlatched` / `latched`。`closed` かつ `latched` を「閉扉」と定義する。

### 2.3 施錠モード（双安定レバーの位置）

`secured` / `coupled`。レバーは電気で切り替え、保持は機械的に行う（[05_latch.md](05_latch.md)）。

### 2.4 コアの論理状態への対応

コア第 3 章の論理状態に 3 軸を次のように対応させる。錠側はこの語を知らなくてよいが、遷移が成立することを要求する。

| 論理状態 | 実体 | 遷移のきっかけ |
| --- | --- | --- |
| `secured` | closed + latched + secured | 閉扉時にレバーが secured 側なら自動で成立（電気不要） |
| `released(n秒)` | ポール一時解放、または n 秒だけ coupled | 解錠 URL、Aliro タップ、管理者操作 |
| `passage` | coupled 固定 | 管理者がオートロックを切る |
| `ajar` | half または open のまま一定時間 | 半ドア警報 |

### 2.5 要求

| ID | 要求 |
| --- | --- |
| R-ST-01 | 扉位置 3 値、掛かり 2 値、施錠モード 2 値を、それぞれ独立したセンサーで検出**すること** |
| R-ST-02 | 状態変化から 200 ms 以内に安全 MCU が通信モジュールへ通知**すること** |
| R-ST-03 | 電源投入・復電時に、センサーから現在の状態を再構成して報告**すること**（記憶に頼らない） |
| R-ST-04 | 半ドアを `closed` と報告しない**こと** |

## 4. 通線・電源

### 4.1 方針

配線種別を 1 つに絞らず、**性質の違う 2 系統 + 予備配管**を扉本体まで通す。USB は建築配線として採用しない。

### 4.2 要求

| ID | 要求 |
| --- | --- |
| R-WR-01 | A 系統として Cat6A 以上の Ethernet ケーブル 1 本を枠から扉本体まで通す**こと**（PoE+ 給電対応） |
| R-WR-02 | A 系統は露出型ドアループまたは扉上部の隠蔽ケーブルトランスファーで扉に渡す**こと**（電気丁番の細線は使わない） |
| R-WR-03 | B 系統として 0.5 mm² × 8 芯以上のシールド付き多芯線 1 本を通す**こと**。用途は電源 2 芯、RS-485/UART 2 芯、無電圧接点 4 芯を想定 |
| R-WR-04 | B 系統は電気丁番経由で**あってもよい**。丁番の導体定格（電流・本数）を仕様書に明記すること |
| R-WR-05 | 予備として呼び径 16 以上の空配管と呼び線を、枠側ボックスから扉内ケーブル溝まで通す**こと** |
| R-WR-06 | 扉内部のケーブル溝は Cat6A（外径約 7 mm）と多芯線が同時に収まり、丁番側から錠ケースまで連続している**こと** |
| R-WR-07 | 枠側に埋込ジャンクションボックスと端子台を標準装備し、A/B 両系統をそこで受ける**こと** |
| R-WR-08 | 扉側給電は DC 12〜24 V を受けられる**こと**。PoE 受電時は扉内で変換すること |
| R-WR-09 | 停電時に「最後の解錠 1 回」と「状態報告」ができるバックアップ電源（スーパーキャパシタまたは小型電池）を持つ**こと** |
| R-WR-10 | ケーブル貫通部は防火・遮音の認定範囲内で処理**すること** |
