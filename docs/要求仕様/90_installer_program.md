## 1. 目的と範囲

AI で作る物が増え、攻撃も増える。作った物を建物に入れて動かし、攻撃と事故のときに止めて戻すのは、現場の人である（コア R-RS-07〜10）。本書は、その人を育てる手順を定める。

| 対象 | 例 |
| --- | --- |
| 施工・保守の業者 | ドア製造者の販売店と施工店の網、設備工事会社。現地調査、据付、引き渡し、一次保守（コア 8.1） |
| 運営者の現場の人 | 民泊、貸家、事業所、管理組合が建物ごとに決める人（コア R-RS-09）。点検、切り離し、止まったときの手段 |
| 製造者の保守の担当 | 更新、二次保守、手順と教材の作成（コア R-RS-05、R-RS-10） |

扱う仕事は六つ：据付、受入れ試験、点検、切り離し、復元、鍵の作り直し。

## 2. 学ぶ物の重み

| 学ぶ物 | どこまで |
| --- | --- |
| コードを書くこと | 浅くてよい。AI が書く |
| テストを読むこと | 何を、どの入力で、何を期待して確かめているかを言える |
| セキュリティ | 鍵と署名、権限の範囲、更新、脆弱性の扱い、攻撃の手口（ルーターを含む） |
| 現場で物に触れること | 置く、配線する、つなぐ、実機で確かめる、止める、戻すを、自分の手で一通り行える |

## 3. 段階

| 段階 | できること | 扉への権限 |
| --- | --- | --- |
| 見習い | 疑似の扉で六つの手順を通す。実機の作業は、施工者の隣で行う | 持たない |
| 施工者 | 据付、受入れ試験、引き渡しを一人で行う | 作業の都度、管理者が出した一時の資格情報だけ（コア R-AC-06、R-AC-10） |
| 保守者 | 点検、切り離し、復元、鍵の作り直しを行う | 同上。作業が終わったら失効を確かめる |
| 現場の責任者 | 建物ごとの手順を決め、訓練を主催し、記録を見る | 同上。鍵の持ち主は運営者と製造者（コア R-RS-03） |

## 4. 手順

### 4.1 据付

1. 現地調査：扉、枠、通線路、弱電盤の場所と給電、回線の種類、ルーターの型番と持ち主を確かめる
2. 機械を置き、配線する。扉の系統（錠、扉のコントローラ、ミニサーバー、読取機）を、ほかの機器と網の上で別の区画に分ける（コア R-NW-02）
3. ルーターを整える：更新を当て、初めのパスワードを変え、外からの口（遠隔の管理、VPN、DDNS、管理画面、回線の事業者の遠隔の設定）を要る物だけにする（コア R-NW-03、R-NW-04）
4. 扉の名前、管理者の公開鍵、信頼する発行者の一覧を入れる（扉コントローラ仕様書 5.2a）。予備の管理者の鍵を作り、公開鍵を扉へ入れ、秘密の部分は封をして扉の持ち主に渡す（コア R-AC-23）。Matter の登録先から受ける命令の範囲と、更新の入れ方を、プロファイルと持ち主の決めに合わせて設定する（コア R-AC-24、R-EL-34）。署名の秘密鍵は持ち帰らず、置き場を記録する（コア R-AC-11、R-RS-03）
5. 時刻を同期する
6. 受入れ試験（4.2）を行う
7. 引き渡し：記録（4.7）を運営者に渡し、作業の一時の資格情報を失効させる。扉の製造番号とモジュールの個体の番号を記録に書き、製造者の個体の台帳と照らす（コア R-RS-20）。作業のために扉を Matter に登録した場合は、その登録先を外す（コア R-AC-24）

工事と受入れ試験に使った鍵は、試験の終わりに消し、扉が鍵の無い状態を返すことを確かめる（扉コントローラ仕様書 R-CT-27）。4 の管理者の鍵は、売り先の管理者が、自分の前で入れる。

### 4.2 受入れ試験

実機で、次を一つずつ行い、結果を要求の番号の下に記録する。

| 試験 | 合格の条件 | 要求 |
| --- | --- | --- |
| 有効な資格情報で解錠し、時間で施錠 | 解錠し、扉を閉じてから設定の秒数で施錠する | 扉コントローラ仕様書 R-CT-09 |
| 扉を開けたまま時間が過ぎる | 開いている間は施錠しない | R-CT-09 |
| 火災の信号を入れる | 連動を入れた扉は解放し、施錠の要求を拒む。入れていない扉は施錠を保つ。どちらも鍵の管理者の決めた設定どおりかを確かめる | R-CT-05 |
| 電源を切る | 設定どおりに解放または保持し、戻すと通常に戻る | R-CT-06 |
| 内側から機械で開ける | 施錠の状態によらず、電気なしで開く | R-CT-07 |
| 知らない発行者、範囲の外の資格情報 | 拒否し、記録に残る | コア R-AC-09 |
| 網を切る | 錠に登録した資格情報で開き、記録が続く | コア R-AC-10、R-NW-05 |
| ルーターを止める | 扉の判断と記録が続く | コア R-NW-05 |
| 扉の系統の線を抜く、電源を切る | 安全側の挙動を保ち、内側から開く | コア R-RS-07 |
| 記録の検査 | 連番と連鎖と署名が合う（`digitaldoor-controller verify` 等） | R-CT-11〜13 |

### 4.3 点検

周期は年に一度以上、製造者が更新を出したとき、攻撃や事故の後とする。

| 項目 | 確かめること |
| --- | --- |
| ルーター | 型番と更新の期間、当てた更新、外からの口の設定、見覚えのない設定とアカウントの有無（コア R-NW-03、R-NW-04） |
| 錠と読取機 | 電池、更新の版、時刻 |
| 記録 | 連鎖の検査が合うこと。伝票が箱に届いていること |
| 信頼の一覧 | 信頼する発行者の一覧が、運営者の決めた物と同じこと（コア R-AC-12） |
| 予備 | 予備の機械が起動し、イメージが最新であること（コア R-RS-08） |
| 機械の解錠 | 内側から電気なしで開くこと |

### 4.4 切り離し

攻撃や事故が疑われるときに行う。

1. 扉が安全側の挙動を保ち、内側から開けられることを先に確かめる
2. 被害が広がる所から順に切り離す：外とつながる口（ルーターの外向きの線）、扉の区画、ミニサーバー
3. 切り離した時刻と理由を記録する（網が止まっていても、紙か手元の記録に）
4. 運営者と製造者に、網が止まっても使える手段で知らせる（コア R-RS-09）

### 4.5 復元

1. 予備の機械に、イメージから一つの手順で戻す。網は要らない（コア R-RS-08）
2. 疑いのある鍵を作り直す（4.6）
3. 受入れ試験（4.2）のうち、解錠、施錠、火災、停電、記録の検査をもう一度行う
4. 切り離した物を一つずつ戻し、記録する

### 4.6 鍵の作り直し

1. 作り直す鍵（発行者の鍵、更新の署名の鍵、記録の署名の鍵、扉の管理者の鍵、予備の管理者の鍵）と、置き場、触れる人を、鍵の目録で確かめる（コア R-RS-03、R-RS-04）
2. 新しい鍵を作り、新しい公開鍵を扉の信頼の一覧に入れ、古い物を消す（管理者の署名つきの変更。コア R-AC-12）
3. 古い鍵で作った資格情報が拒まれ、新しい鍵の物が通ることを確かめる
4. 作り直した日と鍵の識別を記録する

### 4.7 記録の様式

据付、点検、切り離し、復元、鍵の作り直しのたびに、次を残す。

| 欄 | 中身 |
| --- | --- |
| 日時、場所、扉 | いつ、どの建物の、どの扉か |
| 作業 | 6 つの手順のどれか |
| 人 | 作業した人と、立ち会った人 |
| 結果 | 試験と確かめた項目ごとの、合否と値 |
| 機器 | 型番、更新の版、ルーターの外からの口の設定 |
| 次の手当て | 直すことと、期限 |

## 5. 練習

### 5.1 疑似の扉で

疑似の扉（digitaldoor-controller）で、実機の前に、手順を一通り通す。

| 課題 | 行うこと |
| --- | --- |
| 動かす | 疑似の扉を起動し（`digitaldoor-controller serve`）、状態を照会する |
| 開ける | 発行者の鍵で署名つき資格情報を作り、扉に提示して開け、期限で切れるのを見る |
| 拒まれる | 知らない発行者、範囲の外、使用済みの資格情報が拒まれ、記録に残るのを見る |
| 記録を検べる | 記録の連鎖を検べ（`verify`）、伝票を箱に出し（`export`）、公開鍵だけで検べる（`check-box`） |
| 壊して確かめる | テストを読み、実装をわざと一か所壊して、テストが落ちるのを見る |
| 鍵を作り直す | 管理者の署名つきの要求で、信頼する発行者を替え、古い鍵の資格情報が拒まれるのを見る |

### 5.2 実機で

製造者は、実機の訓練台（扉、枠、錠、扉のコントローラ、ミニサーバー、ルーター、電源と火災の信号の模擬）を用意し、受入れ試験、切り離し、復元を、実際の線と電源で練習させる。

### 5.3 年に一度の訓練

建物ごとに、現場の責任者が主催し、運営者の現場の人と保守者が一緒に行う：網を切った状態での復元、切り離し、止まったときの手段（錠に登録した暗証番号、カード、物理鍵）での開扉。

## 6. 認め方

段階を上がるのは、その段階の手順を自分の手で一通り行い、記録を出したときとする。試験の点数ではなく、実際に動かせたかで認める。

認定の制度、会費、商標は設けない（このサイトの仕様と同じ）。誰が何をできるかの名簿は、製造者と運営者がそれぞれ持つ。

## 7. 要求

| ID | 要求 |
| --- | --- |
| R-IP-01 | 製造者は、据付、受入れ試験、点検、切り離し、復元、鍵の作り直しの 6 つの手順書を、製品と一緒に公開し、誰がやっても同じ手順で行える形にする**こと** |
| R-IP-02 | 段階（見習い、施工者、保守者、現場の責任者）ごとに、できる作業と、扉への権限を決める**こと**。施工と保守の権限は作業の都度の一時の資格情報だけとし、作業の後に失効を確かめる（コア R-AC-06、R-AC-10） |
| R-IP-03 | 施工と保守の人は、署名の秘密鍵を持ち帰らず、預からない**こと**。置き場を記録して運営者に渡す（コア R-AC-11、R-RS-03） |
| R-IP-04 | 据付では、扉の系統の区画分け、ルーターの更新と初期パスワードと外からの口、時刻の同期、4.2 の受入れ試験を必ず行う**こと** |
| R-IP-05 | 受入れ試験は 4.2 の項目を実機で行い、結果を要求の番号の下に記録する**こと** |
| R-IP-06 | 点検は年に一度以上、製造者の更新のとき、攻撃や事故の後に、4.3 の項目で行う**こと** |
| R-IP-07 | 切り離しと復元は、4.4 と 4.5 の順で、網が無くても行える手順と予備を持つ**こと**。扉の安全側の挙動と内側からの解錠を、何より先に確かめる |
| R-IP-08 | 作業のたびに、4.7 の様式で記録を残し、運営者が持つ**こと** |
| R-IP-09 | 見習いは、実機の作業の前に、疑似の扉で 5.1 の課題を一通り行う**こと**。製造者は、実機の訓練台を用意する |
| R-IP-10 | 建物ごとに、年に一度、5.3 の訓練を行い、記録に残す**こと** |
| R-IP-11 | 段階を上がるのは、その段階の手順を自分の手で一通り行い、記録を出したときとする**こと**。認定の制度と会費は設けない |
| R-IP-12 | 手順書、練習の課題、記録の様式は公開し（CC BY 4.0）、製品の更新と要求仕様の改版に合わせて直す**こと** |

足した要求の理由と確かめ方（2026-10-18）

- R-IP-01〜12
  - 出どころ：コア R-RS-10（施工と保守の人を育てる手順と教材）、11 の「施工・保守」の前提（4 点セットを設置・保守する業者の育成）、使う人の言葉「人に残るのは、何を作るかを決めることと、出来た物を見て判断すること、と言われてきたけど間違っていた」（2026-10-18）
  - 理由：作った物を建物に入れて動かし、攻撃と事故のときに止めて戻すのは現場の人である。手順が人ごとに違えば、確かめた結果を比べられず、復元もできない。施工と保守の人が鍵や常の権限を持てば、業者に預けた鍵と同じ危険になる
  - 確かめ方：R-IP-01、12 は公開されていることを確かめる。R-IP-02、03 は、作業の後に一時の資格情報が失効していること、秘密鍵の置き場の記録があることを点検で確かめる。R-IP-04〜08 は 4.7 の記録で確かめる。R-IP-09〜11 は、練習と訓練と段階の名簿の記録で確かめる

## 8. 認定・法規（確認先）

| 項目 | 内容 | 確認先 |
| --- | --- | --- |
| 電源の工事 | 扉とミニサーバーの電源の配線が、電気工事士の資格を要する工事に当たるか | 電気工事業者 |
| 防火設備 | 扉の加工と配線が、防火設備の認定に影響しないか | 製造者・設計者 |
| 個人情報 | 点検と復元で触れる記録と名簿の扱い | 運営者 |
