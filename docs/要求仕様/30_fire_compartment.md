## 1. なぜ別文書か

| 観点 | 玄関・室内扉 | 防火区画の扉 |
| --- | --- | --- |
| 設計を決めるもの | 応用側の運用要求 | 建築基準法・消防法と、防火設備としての認定 |
| 錠の最優先機能 | 施錠(玄関)、管理者の入室(室内) | **避難を妨げないこと**、**確実に閉まること** |
| 停電・火災時 | 施錠保持が基本 | 解錠側へ倒す(通電時施錠型相当)のが一般的 |
| 機構 | 双安定レバー(無通電で施錠保持) | 無通電で解錠へ戻る機構が要る場合がある。双安定レバーと矛盾する |
| 認定 | CP、技適、Matter、Aliro | 防火設備・特定防火設備の認定(扉・枠・自閉装置・錠を含む構成で取る)。錠を変えると認定が変わる |

玄関プロファイルの自動車ラッチ + 双安定レバーは「電気なしで施錠を保持する」ことが利点だが、防火区画の扉では「電気なしで解錠へ戻る」ことが求められる場面があり、機構の前提が逆になる。このため別文書とする。

## 2. 前提として確認する法規・認定(製造者・設計者が確定する)

以下は応用側が把握している範囲の項目名で、条文・告示番号と適用可否は設計者が確認する。

| 項目 | 内容 | 確認先 |
| --- | --- | --- |
| 防火設備 / 特定防火設備 | 建築基準法の区分。どちらに当たるかで遮炎時間(20 分 / 60 分)と構造が変わる | 設計者 |
| 常時閉鎖式 / 随時閉鎖式 | 常時閉鎖式は自閉装置(ドアクローザー)で常に閉じる。随時閉鎖式は煙感知器・熱感知器連動で閉じる | 設計者 |
| 避難経路上の扉 | 避難方向に開くこと、避難時に鍵なしで開けられること | 設計者 |
| 自閉・閉鎖の確実性 | 電子錠のラッチが自閉を妨げないこと。閉鎖時に確実に掛かること | 製造者 |
| 認定の範囲 | 扉・枠・自閉装置・錠・ガラス等の構成で認定される。錠の追加・変更は認定の再取得または適合確認が要る | 製造者 |
| 消防法 | 自動火災報知設備との連動(火災信号で解錠)、防火管理者の点検 | 設計者・消防署 |
| 貫通部 | 通線の貫通部の防火処理 | 製造者 |

## 3. 電子錠に対する要求(骨子)

要求 ID は他文書と衝突しないよう `R-FD-nn` を予約する。数値・条件は認定条件に従うので未記入。

### 3.1 避難を妨げない

- 内側(避難側)からは常に鍵・電気なしで開けられること(玄関 R-MC-06 と同じ、ただし避難側の定義は設計者が決める)
- 火災信号(火災受信機の無電圧接点)を受けたら解錠側へ倒し、火災信号が続く間は再施錠しないこと
- 停電時に解錠側へ倒すか保持するかは、扉の位置づけ(避難経路か、区画の境界か)で設計者が決める。電子錠はどちらにも設定できること

### 3.2 確実に閉まる

- 電子錠の「通行」(passage、外ハンドル結合)モードは、自閉装置による閉鎖と掛かりを妨げないこと
- 随時閉鎖式では、扉を開放保持する装置(電磁レリーズ等)は錠とは別の機器であり、錠は開放保持を行わないこと
- 閉鎖・掛かりの状態を管理ソフトに報告すること(防火管理者の点検記録に使う)

### 3.3 機構

- 火災信号または停電で解錠へ戻す必要がある場合、双安定レバーではなく、無通電で「結合」に戻るバネ付きレバーまたは通電時施錠型のアクチュエータとすること
- 自動車ラッチのラチェットとポールは流用できるが、施錠モードの機構は防火区画用の派生品とすること
- 認定の構成に含まれる部品(錠ケース、ストライク、自閉装置)は認定取得時の仕様から変えないこと

### 3.4 電子部・通信

- 通信モジュールと安全 MCU は玄関プロファイルと同一品を使う。安全 MCU のファームに「火災信号入力」と「防火区画モード」を持たせる
- 火災信号入力は安全 MCU に直接入れ、通信モジュールを経由しないこと
- 系統数(1 または 2)は扉の位置づけで決める。区画境界が玄関を兼ねる場合は 2 系統

### 3.5 管理ソフトとの連携

- 火災信号による解錠、閉鎖状態、自閉装置の異常(取れる場合)を履歴に残すこと
- 管理ソフトから防火区画の扉を「施錠保持」に固定する操作はできないこと(避難の妨げになる設定を UI から作らせない)
- 点検モード(手動で閉鎖・掛かりを確認し、結果を記録する)を管理ソフト側に用意する

## 5. 応用側の当面の方針

- 標準版(自己設置)は防火区画の扉を対象外とする。README の免責に明記する
- 防火区画の扉は Enterprise(有償 SI)でのみ扱い、設計者・製造者・消防との調整を含む
- 既存の認定品(MIWA の防火戸対応電気錠など)に無電圧接点で連携する構成を Plan B として持つ(比較別紙 [annex_latch_vs_miwa.md](annex_latch_vs_miwa.md) 第 5 章)
