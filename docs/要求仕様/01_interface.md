## 1. 何を決めるか

扉は 40 年使われる。扉に載るソフト（認証、顔、見守り、宅配との連携）は、月単位で良くなる。機器とソフトを建築時に固定する扉は、竣工の日が性能の頂点で、あとは古くなる一方である。この時間差を解く設計は一つしかない。住む人が、後から選び、替えられることである。

本書が決めるのは、その境界である。**固定するのは 40 年変わらない物（構造と開口）、自由にするのは月単位で良くなる物（機器とソフト）。認定の境界を、この時間の境界に一致させる。**

選べることは、買う側のためだけではない。電気の付く扉を一枚作るとき、錠や機器の型式ごとに切欠きの寸法、通電金具の形、線の芯数、コネクタ、工事区分が変わる。加工図は「扉の型番数 × 機器メーカー数」で増え、治具と部材もその数だけ要り、間違えたときに直すのは防火戸の切欠きである。そして、機器が決まるまで扉の加工に入れない。標準インターフェースは、この掛け算を足し算に変える。切欠きは一つ、通線路は一つ、部品番号は一つ。機器が決まる前に扉を作れる。

## 2. 制度の前提

- 延焼のおそれのある部分に設ける集合住宅の玄関扉には、建築基準法の防火設備（または特定防火設備）としての性能が求められる。満たし方には告示仕様と大臣認定があり、集合住宅の玄関扉の実務は大臣認定品が中心である
- 認定は、扉のパネル単体ではなく、枠・扉・内部の構造材・丁番・錠・通電金具を含む一体の仕様として加熱試験を受けて下りる。認定時に想定していない錠を現場で組み込めば、認定の仕様から外れる
- したがって「公開規格に対応し、どの錠でも現場で載せられる汎用の枠」は、そのままでは成立しない。この制約は事実として受け入れ、設計で答える

認定の境界、別添仕様に列挙できる型式と許容範囲、将来の追加がどの手続きになるかは、指定性能評価機関との事前協議で確定する（第 14 章）。

## 3. 三つの層

| 層 | 部品 | 扱い |
| --- | --- | --- |
| 認定固定部 | 枠、扉、補強、丁番、通電金具、機械錠（ラッチ、デッドボルト、錠ケース）、および機器を取り付けるための開口・彫込み・台座・塞ぎ板・配線経路 | 大臣認定に含める。型式固定。交換は同一型式か、認定リスト（第 9 章）の範囲内 |
| 協議で確定する部分 | 電動アクチュエータ、カメラ、インターホン子機の、扉・枠への取付方法 | 認定側か自由側かの線を、指定性能評価機関との事前協議で確定する |
| 交換自由部 | 機器本体（電動部、リーダー、制御機器、カメラ、通信ユニット） | 認定の外。コネクタ接続で交換できる。枠内には配線だけを通し、電子機器は枠の外に置く |

火災時に扉を枠に拘束するのは機械錠であり、耐熱の挙動は型式ごとに違うので、ここは固定する。電動部やリーダーの機器本体は火災性能に寄与しないが、取り付ける開口・台座・配線経路まで認定と無関係にはできない。だから、**開口・台座・コネクタごと認定に入れて固定し、機器本体だけを交換自由にする**。標準インターフェース（第 4 章）が固定する物と、認定が固定する物を、同じ物にする。

## 4. 標準インターフェース（固定する三点）

| ID | 要求 |
| --- | --- |
| R-IF-01 | 錠取付部の切欠き（開口・彫込み）の寸法を、一種類（必要なら数種類）に固定**すること** |
| R-IF-02 | 錠部周辺のスチール補強と内部の構造材の仕様を固定**すること** |
| R-IF-03 | 接続仕様を固定**すること**。通電金具のコネクタの型式と配線は [10_entrance_house.md](10_entrance_house.md) 第 4 章（A 系統 Ethernet、B 系統 多芯線、予備の空配管）に従い、結線はコネクタの差し込みとし、建具工事と電気工事の責任分界点をコネクタに置く |
| R-IF-04 | 枠内には配線だけを通し、電子機器は枠の外（交換自由部）に置く**こと**。鍵を持つ部分と安全 MCU の置き場は、コア R-EL-35 による |
| R-IF-05 | 機械錠と電動部を分離できる構造とする**こと**。駆動軸の取り合い、手動解錠、停電時の挙動、必要なトルクは、カタログではなく試作で確かめる |
| R-IF-06 | 機器と建物をつなぐ経路に無線 LAN を使わない**こと**。無線はスマートフォンとリーダーの間（NFC、BLE、UWB。Aliro の前提）に限る。有線給電にして電池切れも消す |

切欠きと補強が変わらなければ、別の機械錠の追加を、当初の試験結果から認められる範囲の変更として扱える可能性が生まれる。ただし、それがどこまで軽くなるかを制度が保証しているわけではない。ここが事前協議の要の一つである。

## 5. 機器の開口も同じ

交換自由部の考え方は、錠の電動部に限らない。インターホンの呼出ボタン、カメラ、スピーカーとマイク、リーダーも、扉の標準コネクタにつながる機器として同じインターフェースに載せる。

| ID | 要求 |
| --- | --- |
| R-IF-07 | インターホン子機、カメラ、リーダーの取付開口・台座・コネクタを固定**すること**。機器本体は、[00_core.md](00_core.md) 5.3 の公開規格（カメラは ONVIF / RTSP、USB 接続なら UVC、錠は Matter Door Lock と Aliro など）に従う物なら、製造元を問わず入る |
| R-IF-08 | 開口と配線の規格を宣言する時点で、その規格に合う機器が少なくとも一つある**こと**。合う機器が一台も無ければ、開口は空のままである |

錠は認定リストの範囲内で、機器本体はコネクタ交換で自由（取付開口と台座は認定側で固定）。この二段で、玄関の機器のすべてが選べる物になる。

顔を読むドアホンとカメラは、映像の処理と夜間の照明に電気を使い続けるので、電池では持たない。有線で給電できる開口と通線（R-WR）を標準で持つ扉だけが、この機器を載せられる。リーダーを作らない扉の製造者が、リーダーの載る場所を決める側に立てるのは、給電と通線を持っているからである（[02_reader.md](02_reader.md) R-RD-16）。

## 6. 選べる物の目録

| 選べる物 | どうやって選ぶ | いつ選べる |
| --- | --- | --- |
| 機械錠 | 認定リストの中から | 建築時、交換時 |
| 錠の電動部、リーダー | コネクタ交換 | いつでも |
| インターホン、カメラ | コネクタ交換（適合品リストから、または公開規格に従う物） | いつでも |
| ソフト（認証、顔、見守り） | 公開規格の上で更新、入れ替え | 随時 |
| 扉を通す物（配線） | 標準は R-WR-01〜05 の全部。機器を決めない場合も、空配管と呼び線（R-WR-05）は通す | 建築時。呼び線があれば後から引き直せる |
| 決める時期そのもの | 空の通り道（空配管と呼び線だけ） | 「まだ決めない」を選べる |

| ID | 要求 |
| --- | --- |
| R-IF-09 | 機器を決めないまま扉を作る構成（空配管と呼び線だけ）を選べる**こと**。壁と同じで、建具も一度閉じたら後から線は通せない。故障する物が入っていないので、認定への影響と点検の負担が最小になる |

40 年後に何が要るかを当てることは誰にもできない。当てる代わりに、選択肢と空の通り道を保証する。

## 7. 等級 — 「替えても動く」を測って保証する

扉を渡る線は開閉のたびに動き、動きによる劣化が最大の故障要因である。1 日 10 回の開閉なら、40 年で約 15 万回の屈曲が通電金具とケーブルにかかる。市販のケーブルの屈曲試験の回数は仕様書で確かめ、足りない物は使わない。工場の可動部で毎日曲がり続ける前提の産業用の可動ケーブルは普通に存在し、百万回級の耐久をうたう製品群がある。これは発明の課題ではなく、選定と試験の課題である。

一方、業界は線の寿命を「何年で交換」という経験値で扱っており、「何万回動かしても性能を保つ」という等級はまだない。導通があれば動く制御線の世界だったので、測る必要がなかった。測って証明することが、そのまま商品になる。

| ID | 要求 |
| --- | --- |
| R-IF-10 | 扉を渡る線の耐久を、建具の動き（開き扉は屈曲、引戸は摺動、可動間仕切りは組替え）の回数で試験**すること**。測る物は、銅線（Ethernet、多芯線）は動かした後の伝送性能と給電時の温度、光ファイバーは動かした後の光損失 |
| R-IF-11 | 試験の成績を型番ごとに公表**すること**。既にある性能等級（遮音、断熱、対震など）の隣に並べる |
| R-IF-12 | 点検のときに測る項目を、等級の試験と同じ項目にする**こと**（扉のコントローラは R-CT-23 で伝送性能と給電時の温度を測って記録する） |

全部を初日に揃える必要はない。開き扉 × 標準構成から始めて、売れる順に表の枠を埋める。

## 8. 台帳と点検

選べることは、売った日には完成しない。10 年後も 20 年後も「選べる状態」が保たれていて、初めて約束が果たされる。

| ID | 要求 |
| --- | --- |
| R-IF-13 | 設置のときに、扉に何を通したか（線の種類、コネクタ、等級、機器の型式）を台帳に記録**すること** |
| R-IF-14 | 点検のたびに測定値（伝送性能、給電時の温度、光損失）を台帳に書き足す**こと**。改修のときに「扉の中に何が通っているか分からない」状態を作らない |

機器の交換は、点検の暦のいちばん軽い仕事である。交換自由部は表に付いていて、規格のコネクタを差し替えるだけで認定に触れない。ソフトの更新も同じ暦に載せ、月単位の向上を点検のたびに建物へ届ける。進め方の基準も、ここから決まる。**保守のしやすい物から、少しずつ取り込む。** 空の通り道（壊れる物が入っていない）が最初、次が機器の開口（機器は差し替えるだけで、開口は動かない）、それから扉の中の可動配線である。一番難しい物は、等級の試験データが揃ってから取り込む。

## 9. 認定リストと適合品リスト

リストは二層に分ける。

| ID | 要求 |
| --- | --- |
| R-IF-15 | 認定の別添仕様（機械錠）に、切欠きと補強を共通にした複数の型式と許容範囲を、当初の評価の段階でできる限り列挙**すること**。将来の追加が、当初の試験結果から認められる範囲の変更で済むのか、追加の評価・認定になるのかは、型式の中身と評価機関の判断によるので、追加の道筋そのものを事前協議で設計しておく |
| R-IF-16 | 適合品リスト（交換自由部の機器。インターホン、カメラ、リーダーなど）を、認定とは独立した、製造者自身の検査と保証のリストとして持つ**こと** |

仕様を公開しておけば、錠や機器の各社は聞かずに適合品を開発できる。個別の交渉が「規格に適合したことの告知」に変わる。追加にかかる評価・試験の費用は、リストに載りたい側に持たせる理屈が立つ。

認定固定部の機械錠は、型式固定（認定に入れた型式を数十年同一仕様で供給し続ける）、図面（製造図面を扉の製造者が保持し、供給が途絶しても同一型式を作り続けられる）、改版の同意（型式の仕様変更に製造者の承認が要る）の三条件を契約で満たせる相手から調達する。三条件は確立した事実ではなく、契約で勝ち取る条件である。成立しなければ、機構メーカーへの委託設計・委託製造に切り替え、図面を持つという条件だけは動かさない。

## 10. 図面の公開

| ID | 要求 |
| --- | --- |
| R-IF-17 | インターフェース図面（切欠き寸法、補強の位置、コネクタ、取付条件）を公開**すること**。設計事務所が自分の図面にそのまま貼り込める形（DXF と PDF。必要なら国内の実務で使われる形式も）で配る |
| R-IF-18 | 公開する図面は製品のデータベースから生成し、版を管理**すること**。規格を配る側には版の管理が必須である |

公開しても失う物はない。認定は製造者の名義であり、図面をコピーして同じ扉を作っても認定は付いてこない。公開すると、錠メーカーと機器メーカーが自力で適合品を開発でき、棚に品が集まる。中身を見せない製品が並ぶ市場で、仕様を公開していること自体が採用の理由になる。非公開のまま持つのは、基準錠の製造図面だけである（供給の保険であり、契約上も公開できない）。

## 11. 法的整理

- 防火設備の認定は建築基準法の大臣認定の制度である。消防法（消火器、避難設備など）ではない
- 同一型式への交換は修理であり、認定の仕様のままである。認定リストの体制なら、故障交換はここに収まる
- 別型式への交換は、形式的には認定の仕様から外れる。定期調査・検査での扱いは自治体により分かれるが、現実には街の鍵屋による錠交換が認定の外で日常的に行われている。認定リストの方式は、この現実に「認定の範囲内で選んで替える」という合法の受け皿を与える
- 制約が本当に効くのは、後付けの現場ではなく新築供給の入口である。デベロッパーとゼネコンは認定の仕様の扉しか受け取らない。認定は罰則で効くのではなく、買い手の調達条件として効いている
- 国土交通省の「マンション標準管理規約（単棟型）」第 7 条第 2 項第二号は「玄関扉は、錠及び内部塗装部分を専有部分とする」と定める。「居住者が錠を選び、替える」という商品の値打ちには、管理規約の側にも足場がある

| 規格 | 使う所 | 状態（2026-10-17 に確かめた） |
| --- | --- | --- |
| Aliro 1.0 | 住宅のスマートフォンの鍵。Aliro 準拠のリーダーがそのまま載る扉として、個別の交渉を要らなくする | Connectivity Standards Alliance（CSA）が 2026-02-26 に公開。NFC、BLE、BLE + UWB の三つの経路と、非対称鍵による信頼の枠組み。Apple、Google、Samsung がウォレットの対応を表明 |

| JEM-A（JEM 1427） | 既存のインターホン設備との連動。施解錠の制御と状態監視の 2 値 | 業界標準。孤立した仕様にしない（R-CT-21） |

物理層の公開図面と、認証層の公開規格。二つを重ねると、配線の仕様を公開すれば各社が対応製品を開発できる体制になる。扉の製造者は、適合の検証（認定リスト、適合品リスト）と、図面と等級の公表で、棚の主になる。

## 13. どこから始めるか — 集合玄関機とインターホンの開口

錠の認定リストは、標準の切欠きに合わせた適合品が育つまでに時間がかかる。それより先に動かせる場所がある。集合玄関機とインターホンの開口である。やることは、カタログの対応表を入居規格に格上げすることである。

| | いまの対応表 | 入居規格 |
| --- | --- | --- |
| 書いてあること | 「この機種に対応します」 | 「この開口の寸法・配線・給電・通線の等級に合う機器なら、どれでも入ります」 |
| 寸法を決めるのは | 機器メーカー | 扉の製造者 |
| 機器メーカーの立場 | 界面の所有者 | 開口に入居する側 |
| 買う側 | 対応表にある機種から選ぶ | どの機種でも選べる。後から替えられる |

書いてある事実の量はほとんど変わらない。同じページで、権限の向きだけが逆になる。ここが先である理由は、条件がすでに揃っていることである。供給者が複数いる。切欠きを切っているのは扉の製造者で、物理的な界面はすでに手の中にある。インターホンの更新周期（10〜15 年）と大規模修繕（約 12 年）が重なり、買い手（管理組合）がいる。IP 化と宅配との連携で、集合玄関機の更新需要がいま動いている。

範囲は切る。領分はエントランスユニットの開口と、建具を渡る区間であって、縦系統の配線や住戸内の機器ではない。入居規格の値打ちは、会員だから付くのではなく、測ったから付く（第 7 章）という一点に置く。
