## 1. 何であるか

自動車のサイドドアラッチを建築扉用の電動ラッチに派生させたもの。自動車ラッチをドア用の電子錠に使った例はなく、日本が世界シェア上位を占める自動車ラッチの品質と価格を、数十年設計の変わっていない建築錠の市場に持ち込む。**新規性があり、国際競争力を持てる部品**である。

| 自動車ラッチから引き継ぐもの | 建築扉用に加えるもの |
| --- | --- |
| ラチェットとポールによる 2 段の掛かり（半ドアの検出） | 双安定の施錠レバー（無通電で施錠を保持し、運用中にオートロックの有無を切り替える） |
| 集中ロックのロックレバー（外ハンドルの結合・切り離し） | 扉側給電に合わせたアクチュエータ |
| 10 万回級の耐久、静音、量産の品質と価格 | 建築の公差（垂れ、反り、季節変動）への追従、アンチスラスト |
| 内ハンドルの常時解放（オーバーライド） | 建築の防火・防犯の認定に耐える構成 |

## 1.1 なぜ現状のドア用電子錠ではなく、電動ラッチなのか

現状のドア用電子錠は、既存の錠前（デッドボルト、サムターン）にソレノイドまたはモーターを付加した構成である。施錠の動作と保持に通電が要り、通電時解錠型か通電時施錠型かは施工時に固定され、制御は各社の制御盤かクラウドに依存する。電動ラッチは自動車ラッチの機構を基に、掛かりをラチェットとポール、施錠モードを双安定レバーで持ち、通電は切替時のみとする。コストは機械錠と同じ水準に収まる（下表）。

| 電動ラッチにする理由 | 何が変わるか |
| --- | --- |
| **コストパフォーマンスが高い（機械錠と同じ価格帯で、規格対応の電子錠付き扉になる）** | 機械錠と比較して、扉 1 枚の錠の部分を機構・電子部・通線の順に積み上げると（下の計算）、機構は電動ラッチの方が安く、電子部・通線・現場の取付まで含めた扉全体でも、機械錠の扉に 1〜3 万円を足した価格に収まる。既存の電子錠（有線の電気錠システムで 1 扉 20〜30 万円、後付けの電動サムターンで 5〜8 万円）が届いていない価格帯である |
| 閉めるだけで施錠が成立する | ラチェットがバネで掛かるので、施錠に電気を使わない。停電中も閉めれば施錠される |
| オートロックの有無を運用中に切り替えられる | 双安定レバーで外ハンドルの結合・切り離しを切り替える。切替の一瞬だけ通電し、保持は無通電。既存の電気錠は施工時に型を固定する |
| 半ドアを機構で検出する | 2 段ラッチで半ドアと全閉を機構的に区別する。無人運用の「施錠表示なのに半ドア」が起きない |
| 待機電力がゼロで、動作は一瞬 | 双安定の保持は無通電。電池とバックアップ電源が小さくて済み、停電時も最後の解錠ができる |
| 自動車の耐久・静音・量産品質 | 10 万回級の耐久、静かな動作音、量産の品質と価格。数十年設計の変わっていない建築錠と比べて桁が違う |
| 内側からは常に機械で開く | 自動車のオーバーライド機構。施錠モードによらず内ハンドルで出られる |
| 制御が開いている | 錠の中に Matter / Aliro の認証品と自前の制御を持てる。特定の制御盤やクラウドに閉じず、認証品どうしで交換できる |
| 扉と一体で設計できる | 錠ケースの寸法に縛られず、扉メーカーがハンドルと見付けを設計できる。扉とラッチを同じ会社が作る |
| 日本が強い部品である | 自動車ラッチは日本メーカーが世界シェア上位。その品質と価格を建築の錠に持ち込むのは扉を持つ製造者にしかできない |


**計算（扉 1 枚の錠の部分。仕入れと現場の取付まで。2026-09 の Web 公開価格。推定と書いたものは根拠を併記）**

| 項目 | 機械錠の扉（玄関、2 ロック） | 電動ラッチの扉 | 根拠 |
| --- | --- | --- | --- |
| 機構 | 錠ケースセット（ケース + U9 シリンダー + サムターン + 受座）1.17 万円 × 2 + レバー 0.43 万円 = 小売 2.8 万円。扉メーカーの仕入れはその約半分の **1.4 万円**（推定） | 自動車のモーター付きドアロック ASSY は純正補修部品の小売で 1.1〜1.3 万円。補修部品の小売は自動車メーカーへの納入価格の 3〜4 倍が通例なので、納入価格は 0.3〜0.4 万円（推定）。年 1〜2 万個の数量で作る派生品はその 2 倍前後の **0.5〜1 万円**（推定）。ラッチ 1 個で掛かりと施錠を兼ねるので 2 ロックは要らない | MIWA LA レバーハンドル錠、トヨタ純正 69030 / 69040 系の販売店表示 |
| 電子部 | なし | 系統 1（NFC + BLE + セキュアエレメント）0.5〜1 万円、系統 2（Thread + Ethernet）0.5〜1 万円、安全 MCU 基板 0.3〜0.5 万円 = **1.3〜2.5 万円**（認証品モジュールの相場からの推定）。Matter / Aliro の認証品は普及に伴って価格が下がる部品であり、この項目は今後縮む | Matter / Aliro 対応モジュールの価格帯 |
| 通線・電源 | なし | 電気丁番またはドアループ 0.5〜1 万円 + 多芯線・電源部 0.5〜1 万円 = **1〜2 万円**。工場で扉セットに組み込む | 通電金具の価格帯 |
| 現場での錠の取付 | 現在は錠と扉が別々に納入され、現場で錠を取り付けて調整する。建具工または鍵屋の工賃 **1〜2 万円**（推定） | 工場で扉セットに組み込んで出荷するので、現場は給電の接続のみ **0.5 万円**（推定） | 錠の取付工賃の相場 |
| 錠の部分の合計 | **約 2.4〜3.4 万円**（仕入れ + 現場取付） | **約 3.5〜6 万円**（仕入れ相当 + 現場接続） | |
| 差 | | **+1〜3 万円**（電子部の価格低下で縮む） | この差額で、ウォレットの鍵、時間限定の鍵、記録、遠隔の失効、規格対応、規格改定への追従が付く |
| 使い続ける費用 | 合鍵の作製、紛失や退去のたびのシリンダー交換 1.5〜3 万円 | 鍵の発行と失効はソフトで、費用なし | 管理物件・賃貸では 1〜2 回の退去で差額を回収する |
| 既存の電子錠（参考） | 有線の電気錠システム：錠 3.6〜4.9 万円 + 制御盤 5.3 万円 + 配線工事 10〜20 万円 = 1 扉 20〜30 万円。後付けの電動サムターン：本体 4.3 万円 + 取付 = 5〜8 万円 | | 電動ラッチの扉は、これらの 1/4〜1/6、または同額以下で、扉と一体の規格対応になる |

機構の推定の根拠：自動車の補修部品は、納入価格に流通と補修の費用を乗せて小売価格になるため、小売が納入価格の 3〜4 倍になるのが通例である。年 1〜2 万個という数量は自動車の量産（年数十万〜数百万個）より少ないので、型と工程の償却で単価は上がるが、それでも機械錠の錠ケース 1 個（仕入れ 0.6〜0.7 万円）と同じか安い。この数字は Go-Tech の 1 年目に試作と見積りで確定する。

既存の電気錠との詳しい比較は [annex_latch_vs_miwa.md](annex_latch_vs_miwa.md)。

## 2. 2 つの使われ方

| 使われ方 | 内容 |
| --- | --- |
| 扉セットの中核 | ドア製造者の電子錠埋込型ドア（玄関、住戸玄関、室内扉 A2）に組み込み、国内のオープン規格ドア事業で売る。第二の開発目標（[10_entrance_house.md](10_entrance_house.md)） |
| 部品として | 性能（耐久、静音、保持力、消費電力）の数字で売る。国内の扉・錠メーカーへ販売し、海外へは輸出または技術提携で出す。国内の 3 年で数字と実績を作り、規格対応が世界で落ち着いた後に「機構が違う」部品として入る |

---


## 3. 採用理由（応用側の判断）

- 閉めるだけで掛かる。施錠に電気を使わないので、停電中も閉めれば施錠状態が保てる
- オートロックの有無を、機構を変えずに設定で選べる
- 静音、耐久実績（10 万回級）、既存サプライヤがある
- 半ドアを機構レベルで検出できる

## 4. 要求

| ID | 要求 |
| --- | --- |
| R-MC-01 | 扉を閉める動作だけで、電気を使わずに掛かり**すること**（バネ式ラチェット） |
| R-MC-02 | 2 段ラッチとし、半ドアと全閉を機構的に区別**すること** |
| R-MC-03 | 施錠モード（外ハンドルの結合／切り離し）は**双安定**とし、切り替え時のみ通電、保持は無通電で**あること** |
| R-MC-04 | 停電しても施錠モードが機械的に保持され**ること** |
| R-MC-05 | 一時解錠のため、ポールを電動で解放する手段を持つ**こと**（動作時間は 0.3〜10 秒で設定可能が**望ましい**） |
| R-MC-06 | 内側ハンドルは施錠モードによらず常に機械的にラッチを引ける**こと**。内側を無効にする機能を持たない**こと** |
| R-MC-07 | ラッチはカード等で押し戻せない構造（アンチスラスト／デッドラッチ）で**あること** |
| R-MC-08 | 建具の垂れ・反り・季節変動に追従できる噛み合い代を持つ**こと**（数値は製造者が定める） |
| R-MC-09 | 電動デッドボルトを追加**してもよい**。その場合も R-MC-06 を満たし、状態を報告すること |
| R-MC-10 | 動作音は住宅の夜間に配慮した水準で**あることが望ましい** |

## 5. 性能の数字（部品販売で示すもの）

| 項目 | 目標の置き方 |
| --- | --- |
| 耐久 | 開閉と施解錠の回数。自動車 OEM 品の水準を建築で確認する（受入れ試験 T-02 の 1,000 回は最小。量産前に 10 万回級を製造者側試験で） |
| 静音 | 掛かり音と施解錠音（dB）。住宅の夜間に配慮した水準（R-MC-10） |
| 保持力 | ラッチとストライクの静的荷重（建築の防犯等級の試験に耐える値を製造者が定める） |
| 消費電力 | 双安定の切替 1 回あたりの電力量と、待機電力ゼロ（保持は無通電） |
| 環境 | 防雨（JIS C0920 等級 3 相当を目標）、温度範囲、結露・砂塵 |
| 公差追従 | 噛み合い代（mm）と、垂れ・反りの許容量 |

数字はすべて製造者が定め、受入れ試験と納品検査の記録に残す。部品販売ではこの表がそのまま売り物になる。
