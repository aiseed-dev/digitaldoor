## 1. 玄関との違い

| 観点 | 玄関扉 | 室内扉 |
| --- | --- | --- |
| 相手 | 建物外の侵入者 | 既に建物内にいる利用者 |
| 守るもの | 建物全体 | 部屋の中の物と、部屋の利用の秩序 |
| 失敗したときの最悪 | 侵入・盗難 | 閉じ込め、管理者が入れない、間違った部屋が開く |
| 設計目標 | 破られない | **管理者が錠を壊さずに必ず入れる**。利用者が閉じ込められない |
| 認定 | 防火・CP | 原則不要（防火区画の扉は別文書） |

このため室内扉は 2 系統を要求せず、非常手段も簡単化する。電子部は「錠であれば Matter」を基準にし、Matter Door Lock 認証品（Thread）なら製造元を問わない。ゲートウェイは Matter コントローラ兼 Thread ボーダールーターとして室内錠を扱う。

---

## 2. 構成

```
 室内錠または壁側コントローラ（Matter Door Lock 認証品。Aliro 対応が望ましい）
    │ Thread                          │ 有線接点（任意）
 ゲートウェイ（Matter コントローラ + Thread ボーダールーター。部屋の外にあってもよい）
```

- 電子部は Matter Door Lock 認証品であれば製造元を問わない。玄関の系統 1 / 系統 2 の区別は室内扉には適用しない
- Aliro のタップ解錠は錠内で検証されるので、ゲートウェイ不在でも動く。鍵の登録は Matter Door Lock クラスタの Aliro 機能でゲートウェイから行う
- 電源は方式 A は**通線して扉側給電**（玄関の B 系統相当の多芯線 + バックアップ電池）、方式 B は壁側コントローラへの給電。Ethernet は要求しない。電池のみの運用は既存扉への一時的な後付けに限る
- 方式 B / B′ では**壁側の装置は最小コントローラ**とする。中身は電源、ストライク駆動と扉センサー入力、Matter（Thread）と Aliro（NFC リーダーは扉脇に分離可）、バックアップ電源だけ。OS、管理ソフト、画面、サーバー機能は持たない。錠の電子部を扉ではなく壁に置いただけの Matter Door Lock デバイス、と考える
- **最小コントローラは扉・枠と一緒に出荷する。** Matter Door Lock 認証品であれば製造元を問わない。方式 B / B′ の扉は電子錠埋込型ではないので、ドア製造者の製造範囲外。ドアセット（扉 + 枠 + ストライク + 扉脇リーダー + コントローラ）の組合せと同梱は、製造者がセット販売に含める場合はその調達品として、それ以外は建具業者または施工業者（90_installer_program.md）が担う。枠への取付けと配線・試験を事前に済ませておくのが望ましいが、必須は同梱までとする。既設扉・既設枠への後付けの場合のみ、コントローラを単体品として別置きする

```
[方式 B / B′ の壁側装置 = 最小コントローラ]
 電源（12/24 V または PoE、バックアップ）
  ├ ストライク駆動 / 扉センサー入力 / 有線接点
  └ Matter（Thread）+ Aliro（NFC + BLE、扉脇リーダーとして分離設置可）
        │ Thread
 ゲートウェイ（Matter コントローラ。部屋の外でもよい）
```

## 3. 機構（扉と枠の条件で選ぶ）

| 方式 | 構造 | 向く場合 | 電子部の位置 |
| --- | --- | --- | --- |
| A. クラッチ式レバー錠 | 外レバーは通常切り離し（空転）。有効な資格情報でモーターが外レバーを結合する。内レバーは常にラッチを引く。内側に在室ロック（外レバーだけを機械的に切り離す）を付けられる | 扉側に通線でき、在室ロックや扉側の意匠が要る場合 | 扉側。**通線して給電**、バックアップ電池 |
| A1. クラッチ式既製品 | 錠ケース内のクラッチ機構。市販の Matter Door Lock 認証品（Aliro 対応が望ましい）。外部給電端子を持つ機種を選ぶ。2026-09 時点で Matter 対応のクラッチ式錠は少なく、市場調査が要る | 既存扉への後付け | 扉側。通線給電（電池のみは一時運用） |
| A2. 自動車ラッチ派生 | 玄関の自動車ラッチのロックレバー（集中ロック機構）をクラッチとして使う。内ハンドルはワンモーション解放、内側ロックノブが在室ロック。通線給電なのでアクチュエータは玄関と同一。電子部は玄関の系統 2（Matter）相当を 1 系統で載せる | ドア製造者が扉ごと供給する場合。**製造者の室内向け製品はこの A2 のみ** | 扉側。通線給電 |
| B. 電気ストライク + 空錠 | 扉は普通のレバー錠。枠側のストライクが電気で解放する。通行モードはストライクの解放保持 | 枠を加工でき、壁側にコントローラを置ける場合 | 壁側の最小コントローラ。扉は無電化 |
| B′. 面付け型（枠を切欠けない場合） | 面付け電気ストライク、または枠上部の電磁ロック（フレームレスのガラス扉はパッチ錠 + 電磁ロック）。電磁ロックは通電時施錠型のみで常時通電 | 枠の切欠きができないが面付けと配線はできる場合 | 枠側面付け。電子部は壁側の最小コントローラ |

A1 と A2 は同じ機能要件（3.3）を満たす実装の違いで、選択の基準は「既存扉か、製造者が扉を供給するか」だけである。

### 3.0 選定フロー

B が最も安いが、枠側の条件で成立しないことが多い。次の順で決める。

| 順 | 条件 | 方式 |
| --- | --- | --- |
| 1 | 在室ロックや扉側の意匠が要る | A（既存扉 A1、製造者供給 A2）。通線あり |
| 2 | 製造者供給のドアセット（適合コントローラ同梱、R-IN-33）を入れられる、または既設枠を切欠けて壁にコントローラを置け配線できる | B |
| 3 | 既設枠を残す必要があり、切欠けないが、面付けと配線はできる（既設鋼製枠、防火枠、賃貸の原状回復） | B′（面付けストライクを優先。電磁ロックは常時通電と停電時解錠を許容できる部屋のみ）。コントローラは単体品（R-IN-35） |
| 4 | 枠側に何も付けられない・配線できない（アルミパーティションの薄枠、コントローラから枠への経路がない）、または扉側に通線できる | A（通線あり）。在室ロックは省略可（R-IN-27） |
| 5 | 扉側にも枠側にも配線できない | A1 の電池運用（一時運用扱い、R-IN-06） |

枠側の条件は設置前に現地調査で確認する（R-IN-26）。同じ建物内で部屋ごとに方式が混在してよく、どの方式も Matter Door Lock として管理ソフトからは同じに見える。

### 3.1 コアの論理状態への対応

| 論理状態 | A. クラッチ式（A1 / A2 共通） | B. 電気ストライク |
| --- | --- | --- |
| `secured` | クラッチ切り離し + ラッチ掛かり | ストライク保持 + ラッチ掛かり |
| `released(n秒)` | クラッチ結合 n 秒 | ストライク解放 n 秒 |
| `passage` | 結合保持（無通電で保持できる双安定機構が**望ましい**。A2 は双安定レバーで標準的に満たす） | ストライク解放保持（通電） |
| `ajar` | 扉位置センサー | 扉位置センサー（枠側） |

## 5. 錠を壊さずに入る手段（R-IN-10）

| ID | 要求 |
| --- | --- |
| R-IN-10 | 次の手段のうち**2 つ以上**を備え、いずれも錠・扉・枠を破壊せずに管理者が入室でき、使用した事実が履歴に残る（センサーまたは手動記録）**こと**。組合せは製造者が提案する |

| 手段 | 内容 | 長所 | 短所 |
| --- | --- | --- | --- |
| a. 非常給電パッド | 外側に 9 V 角形電池または USB-C の給電端子。給電後は通常の Aliro / Matter で解錠 | 電池錠の一般的な運用で分かりやすい。電子部が生きていれば確実 | 電子部の故障には無力 |
| b. 管理者用機械キー | 外側にマスターキー対応シリンダー（カバー下） | 電子部が全滅しても入れる。鍵屋が扱える | 鍵の物理管理が必要。ピッキング耐性は不要と割り切る |
| c. 有線接点リリース | ゲートウェイの GPIO から多芯線経由でポール解放（A）、または壁側コントローラの接点（B） | 無線が死んでも管理ソフトから開く。履歴が自動で残る | A は通線が要る |
| d. カバー下の手動リリース | セキュリティトルクス等で外すカバーの下に、ポールを手で解放するレバー | 鍵も電気も不要 | 工具さえあれば誰でも開く。在室ロックのある扉には向かない |
| e. 抜き差し丁番（外開き扉のみ） | 丁番ピンを抜いて扉ごと外す | 錠に一切手を加えない | 扉が重い。内開きでは使えない |

推奨の組合せ：方式 A（通線あり）は **c + b**（有線接点は多芯線に乗る。a はバックアップ電池も切れた場合の予備）、方式 B / B′ は **c**（壁側コントローラの安全 MCU に直結なので扉への通線不要）+ **b または d**。方式 B / B′ では a は壁側コントローラへの非常給電に相当する。

## 6. 玄関プロファイルとの部品共通表

| 部品 | 玄関 | 室内 |
| --- | --- | --- |
| 機構 | 自動車ラッチ（2 段、アンチスラスト、双安定レバー） | A1: クラッチ式既製品、A2: 同じ自動車ラッチ本体、B: 電気ストライク + 空錠、B′: 面付けストライクまたは電磁ロック |
| 安全 MCU | 2 ポート | 不要（Matter Door Lock 認証品の内部構成に任せる） |
| 系統 1 モジュール | あり | なし（Matter + Aliro の 1 系統に統合） |
| 系統 2 モジュール | あり | Matter（Thread）。これが室内扉の唯一の系統 |
| 電源 | 扉側給電 + バックアップ | A: 扉側給電 + バックアップ電池、B / B′: 壁側コントローラの給電（12/24 V または PoE）+ バックアップ（電磁ロックは常時通電） |
| 通線 | Ethernet + 多芯線 + 空配管 | A1 / A2: 多芯線のみ（電気丁番またはドアループ）、B / B′: 製造者供給ならコントローラ同梱（工場配線済みが望ましい）。後付けは単体コントローラから枠・リーダーまでの配線 |
| 非常手段 | 未決（R-SF-06） | R-IN-10 の 2 つ以上 |
