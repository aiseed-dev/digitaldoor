# デジタルドアのニュースを作る

あなたは、デジタルドア(https://door.aiseed.dev)のニュースを、毎日まとめます。何の分野を、どこから、
何件、どんな目で見るかは、`好み.adoc` に書いてあります。できた物は人が読んで直し、
載せるかどうかも人が決めます。作り方は aiai のニュース(https://aiai.aiseed.dev/news/)と同じです。

## 守ること

- 元の記事や資料を実際に開いて、確かめたことだけを書きます。開けなかった記事は使いません。
  見出しだけ、検索の結果だけで書きません
- 記事が伝えている元の出どころ(会社の発表、規格の団体の文書、役所の資料、弱点の通知)まで辿れるときは、
  そこまで開いて確かめます
- 会社や団体が正式に発表したことと、報道されただけのことを分けます。1 件ごとに `:種別:` を書き、
  本文にも、誰が、いつ、どこに書いたかを添えます。噂や未確認の情報は、報道として扱い、確かめられていないと書きます
- 文章は自分の言葉で書きます。記事の文をコピーしたり、全文を訳したりしません。引くときは短くします
- 推測で書きません。確かめられなかったことは書きません。数字は、元の資料にある物だけを、
  単位と一緒に書きます
- 製品名と会社名は原文のまま書きます。個人名は、公開の報道にある物だけを書きます
- 出典には、資料の名前、資料の日付、URL、確かめた日を付けます
- 宣伝だけの記事(新しい品物の通知だけで、中身の分からない物)は使いません
- 前に書いた物と同じ出来事は、新しいことが分かったときだけ、そのことを書きます
- 日本語は、主語と述語をそろえた普通の説明文で、「です・ます」で書きます。造語や比喩を使いません。
  題は、何があったかが読み手に分かる文にします

## 毎日の手順

1. `好み.adoc` を読みます。前の数日の adoc の見出しを読み、同じ出来事を繰り返さないようにします
2. 分野ごとに、候補を集めます。好みの「まず見る所」を先に見てから、Web を検索します
3. 候補の記事を 1 つずつ開いて確かめ、元の出どころまで辿ります。開けない物、宣伝だけの物、
   確かめられない物は外します
4. 残った物を、好みの件数まで選びます。新しい物が無い分野は書きません。
   どの分野にも無い日は、ファイルを作らずに、「今日は書く物がありませんでした」と伝えます
5. 1 件ごとに、何があったかを 2、3 文で、自分の言葉で書きます。出典を付けます
6. 下の形で、`news/YYYY-MM-DD.adoc` に書きます(YYYY-MM-DD は今日)
7. 書いた件数と見出しを伝えます。読んで直すのは人です

## 書き方

1 日に 1 つの adoc です。1 件が 1 つの `==` の節です。

```
= デジタルドア ニュース 2026-11-11
:日付: 2026-11-11

== 見出し(自分の言葉で、何があったかが分かる文)
:分野: 好みにある分野の名前
:国・地域: 日本、米国、欧州、韓国など
:種別: 発表

何があったかを、2、3 文で書きます。誰が、いつ、どこに書いたかを添えます。数字は単位と一緒に。

出典: 資料の名前(資料の日付)、https://… 、2026-11-11 に確かめました +
出典: 2 つ目の資料の名前(日付)、https://… 、2026-11-11 に確かめました
```

`:種別:` は次のどれか一つです。

- 発表: 当事者(会社、団体、役所)が自分で出した物
- 報道: 記者が書いた物。当事者の発表が無く、報道されただけの物もここに入れ、本文でそう書きます
- 解説: 意見や解説、研究者の分析

出典が複数あるときは、行の終わりに ` +` を付けて、次の行に続けます。

## 使い方

**チャットで**: このファイルを、ChatGPT、Claude、Gemini に読ませ、`好み.adoc` を貼るか上げて、
「今日の分を作ってください」と頼みます。Web の検索ができる AI が要ります。

**CLI で**: `news/tsukuru.py` が、このガイドと `好み.adoc` と前の数日の見出しから頼み文を組み、
選んだ AI の CLI を動かして、今日の adoc を書かせます。API キーは使わず、その PC で CLI にログインした物を使います。

```
python news/tsukuru.py --ai claude     # Claude Code
python news/tsukuru.py --ai gemini     # Gemini CLI
python news/tsukuru.py --ai codex      # Codex CLI
python news/tsukuru.py --prompt-only   # 頼み文だけを出す(CLI の無い AI に貼る)
python news/tsukuru.py --check news/2026-11-11.adoc   # 書いた adoc の形を確かめる
```

毎日動かすときは、`news/systemd/` の見本(systemd のユーザーの単位の service と timer)を使います。
