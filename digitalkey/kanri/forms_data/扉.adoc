= 扉
:様式: 扉
:持ち主: 管理者
:書ける: 管理者

この発行者が管理する扉を一つ書く(R-AC-09)。名前は扉のコントローラに据付で入れた名前と同じにする。
同じ名前でもう一枚書くと、後の伝票が今の値になる。撤去した扉には、新しい申請と発行を出さない。

名前:: [varchar(40), not null] 扉の名前。資格情報の doors に入る。「,」は使わない
経路:: [varchar(200), not null] この扉で使う経路を「, 」でつなぐ。署名つき資格情報、門番を通す錠、物理キー から選ぶ
場所:: [varchar(100)]
記録の公開鍵:: [varchar(64)] 扉の記録の鍵の公開鍵の 16 進。記録の伝票の受け取り(段 2)で使う
状態:: [varchar(4), in ('使用', '撤去'), not null]
失効の最長の分数:: [integer, check (失効の最長の分数 >= 1)] 扉に据付で入れた失効の通知の古さ(revocation_max_age_s)を分で書く(秒 = 分 × 60。R-AC-14)。空は決めていない(扉はその規則を使っていない)。二枚目で省くと空に戻る
役:: [varchar(10), in ('管理者', '名簿の係', '承認する人', '運用', '監査', '本人', '初期化'), not null] 書いた人がこの伝票で使った役。初期化は、置き場を作る時の最初の二枚だけ
