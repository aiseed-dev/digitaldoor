= 役の割り当て
:様式: 役_割当
:持ち主: 管理者
:書ける: 管理者

名簿の主体に、操作の役を付ける、外す(設計書 2 章)。本人の役は、有効な主体の全員が持つので、割り当てない。
発行者はシステムの役なので、人に割り当てない。一人が複数の役を持ってよく、操作のたびに使う役を一つ選ぶ。
