= 権限の失効
:様式: 権限_失効
:持ち主: 管理者
:書ける: 管理者, 名簿の係

権限を止める。発行と申請の伝票は変えず、この伝票で打ち消す。書いた時から効き、門番を通す錠は次の要求から開けない。
一人の全経路を止める時は、その主体の止めていない権限の全部に一枚ずつ書く(R-AC-15)。機器を紛失か廃棄にした時は、その機器を対象にした止めていない権限の全部に一枚ずつ書く。

権限:: [varchar(40), not null] 権限_申請の伝票の番号
主体:: [varchar(40), not null]
範囲:: [varchar(10), in ('一人の全経路', '一つの権限', '機器の停止'), not null] 機器の停止は、機器を紛失か廃棄にした時に、その機器を対象にした権限を止めた物
理由:: [varchar(200), not null]
役:: [varchar(10), in ('管理者', '名簿の係', '承認する人', '運用', '監査', '本人', '初期化'), not null] 書いた人がこの伝票で使った役。初期化は、置き場を作る時の最初の二枚だけ
