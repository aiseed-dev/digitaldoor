= 網の区画
:様式: 区画
:持ち主: 管理者
:書ける: 管理者

網の区画を一つ書く(R-NW-02)。扉の系統、事務、来客、設備など、分け方は管理者が決める。
同じ名前でもう一枚書くと、後の伝票が今の値になる。廃止した区画には、新しく機器を載せない。

名前:: [varchar(40), not null] 区画の名前。「,」は使わない
説明:: [varchar(200)] どの機器をつなぐ区画か、ほかの区画とどう分けているか
状態:: [varchar(4), in ('使用', '廃止'), not null]
役:: [varchar(10), in ('管理者', '名簿の係', '承認する人', '運用', '監査', '本人', '初期化'), not null] 書いた人がこの伝票で使った役。初期化は、置き場を作る時の最初の二枚だけ
