= 失効の一覧の配布
:様式: 失効_配布
:持ち主: 管理者
:書ける: 管理者, 運用

失効の一覧のある世代が扉に届いたと確かめた事を書く(R-AC-22)。扉の GET /revocation の応答や扉の画面を、人が見て書く。
一覧を扉へ運ぶのは、人、利用者の端末、別の道具で、このソフトは網を使わない(R-AC-19)。
扉に届いたと記録された一番大きい世代が、その扉の今の世代になる。

扉:: [varchar(40), not null] 扉の名前
世代:: [integer, not null, check (世代 >= 1)] 扉が受けたと確かめた一覧の世代
日時:: [datetime, not null] 扉が受けたと確かめた日時
備考:: [varchar(200)] 運び方など
役:: [varchar(10), in ('管理者', '名簿の係', '承認する人', '運用', '監査', '本人', '初期化'), not null] 書いた人がこの伝票で使った役。初期化は、置き場を作る時の最初の二枚だけ
