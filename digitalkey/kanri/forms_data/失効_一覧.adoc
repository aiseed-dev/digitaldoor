= 失効の一覧
:様式: 失効_一覧
:持ち主: 管理者
:書ける: 発行者

発行者の鍵で署名する失効の一覧(扉コントローラ仕様書 5.2c)を作った事を書く(R-AC-22)。
一覧は、その時に止めてあって期限を過ぎていない署名つき資格情報の識別の全部で、差分ではない。
署名は台帳に持たない。同じ世代、発行時刻、識別から、発行者の鍵で同じ一覧を組み立て直す。
失効が無くても、扉の知らせを新しく保つために作ってよい(識別は空)。

世代:: [integer, not null, check (世代 >= 1)] 一覧の generation。台帳の最後の一覧の世代に 1 を足した数
発行時刻:: [integer, not null] 一覧の issued_at(unix 秒)
識別:: [text] 失効した資格情報の識別を「, 」でつなぐ。実体_発行を台帳に書いた順。無ければ空
操作者:: [varchar(40), not null] 一覧を作る操作を動かした主体の識別
役:: [varchar(10), in ('管理者', '名簿の係', '承認する人', '運用', '監査', '本人', '初期化'), not null] 操作者がこの操作で使った役
