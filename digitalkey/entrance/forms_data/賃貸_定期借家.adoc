= 定期建物賃貸借(貸家)
:様式: 賃貸_定期借家
:持ち主: 経営者
:書ける: 経営者

借地借家法第38条の定期建物賃貸借。契約は1ヶ月以上。掃除と寝具は借主が管理する。
中途解約は、第38条第7項による解約を除いて認めない。前家賃は契約時に受け取り、敷金を1ヶ月分預かる。
