# 01 在庫表を書く

今ある秘密を全部、一件ずつ `inventory.toml` の `[[secret]]` に書きます。書くのは、名、種類、置き場、持つ人、役、作った日、期限、回す周期、なくした時、漏れた時です。**値は書きません。** 置き場は「サーバー:パス」か「紙/金庫」の名で書きます。

```toml
[[secret]]
id = "web1-app-env"
kind = "token"                # password | token | key | cert | passphrase | other
where = "web1:/etc/app/env"
holder = "suzuki"
role = "業務のサーバーが外の API を呼ぶ"
made = 2026-11-04
expires = 2027-05-04
rotate_days = 180
lost = "token を失効し、新しい token を発行して env を書き直す"
leaked = "失効 → 記録で範囲 → 作り直し → 知らせる"
```

`value` という欄があると、kagi は読まずに止まります。

## 探す所

サーバーの `/etc` とホームのディレクトリ、ルーターと VPN 機器の管理画面、ブラウザに保存したパスワード、スクリプトの中、業者が置いていった物、辞めた人の物。見つけた物は全部書き、消す物も一度は書いてから消します。

## 走査で手伝わせる

```bash
kagi scan /etc/app ~/app deploy
```

出るのは `path:line  種類` だけで、値は出ません。出た場所の物が在庫表にあるかを見て、無ければ足すか消します。`--exclude GLOB` で外す場所を指定できます。

## 確かめ方

`kagi check inventory` が、抜けも期限切れも出さなくなるまで直します。`--days N` で、期限が近い物の日数を変えられます(既定は 30 日)。
