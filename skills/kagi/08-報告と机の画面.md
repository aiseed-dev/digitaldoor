# 08 一枚の報告と机の画面

## 一枚の報告

```bash
kagi report
```

在庫の数と期限、口の差、走査の数、記録の検証が一枚の Markdown で出ます。口と走査は `--ss FILE --host NAME --scan PATH... --exclude GLOB` を付けた時だけ見ます。これを読んで「合っている」と言えたら、次の歩(置き場、控え、根の鍵と二人の確かめ)へ進みます。報告は印刷して紙に残してもかまいません。

## 机の画面

```bash
kagi app --dir ~/kagi-data
```

係の PC に窓が一つ開きます(Flet の PC 版。網には出しません)。`flet` が要ります(`.venv/bin/pip install -e 'kagi[app]'`)。

画面は四つです。

- **機械。** 上の釦で機械を選びます(`直す 9`、`よし`、`写し無し`)。「写しを取る」で今の形を読み、直す物が一件ずつ、手の文と並んで出ます。手の右の印で写し、機械の端末に貼ります。終わったら、もう一度「写しを取る」を押します。一台目は「機械を足す」の欄から足します。
- **鍵。** 鍵の一覧と「鍵を足す」(渡すのは `.pub` だけ)。
- **在庫・口・記録。** 在庫・口・走査・記録の札と報告の釦。在庫の下に「サーバーの外の鍵」と「在庫表に一件足す」があります。口は `ss -ltnp` の写しを選び、走査は場所を選びます。記録は actor・action・detail を書いて「一行足す」を押します(署名の鍵は 02)。
- **人の出入り。** seed のサーバーの門を管理する画面です(下)。

動いているべきサービスを機械の `services` に書いておくと、止まった時に「直す」に出ます。報告の釦は `report-<日>.md` を作業の場所に書き、画面にも出します。鍵の値は画面に出ません。

## 人の出入り(seed のサーバーを前提にした画面)

この画面は、seed のサーバー(https://github.com/aiseed-dev/seed )の管理の口(`/api/admin/*`)を相手にします。seed を動かしていない会社では使いません。ほかの三つの画面は seed が無くても使えます。

- 要るのは、サーバーの URL(https。http は断ります)と、管理者の token(seed のサーバーの機械の上で人が出した物)です。「繋ぐ先」に入れて「保存」すると、作業の場所の `seed-admin.json` に持ち主だけが読める形(600)で置かれ、画面には「入っています」とだけ出ます。在庫表にこの token の一件が無ければ、そう出るので「在庫表に一件足す」から書きます(値は書きません)。
- 上から、今の状態、気を付ける事(打つコマンドは右の印で写し、サーバーの端末で読んでから打つ)、人に渡す token、載せる前の記録、公開された記録、操作の記録が並びます。
- 載せる前の記録は「読む」で全文と写真を見て、名前、住所、他の人の事、場違いな物が無いかを読み、「載せる」か「戻す」(一言を添えます。送った人に届きます)を選びます。
- 操作の記録には、誰が何をしてどうなったかが人の言葉で並びます(Claude と話した行は「Claude と話した」、結果は「通した」か「断った: …」)。
- token は、渡す相手の名前、できる事、期限(1〜365 日)を入れると「出す」が押せます。出た token は一度だけ出るので、写してその人にだけ渡します。
- 取り消す、全部取り消す、受け付けを止める・再開する、載せる、戻す、取り下げる、一言を消すは、どれも二度押しです(一度目で釦が「本当に…」に変わります)。止めている間は、どの画面でも上に赤い帯が出ます。
- ここでした事は kagi の記録にも一行ずつ残ります(token の値は書きません。署名の鍵が無い時はその事が出ます)。

**サーバーの外の鍵。** 「人の出入り」で読んだ、サーバーに Claude と Pl@ntNet の鍵が在るか無いかを、在庫表の行と並べます。在庫表の行は、名か置き場に `anthropic`(か `claude`)、`plantnet` を含む物がその鍵の一件です。サーバーに在るのに在庫表に無ければ「直す」なので、「在庫表に一件足す」で、名、置き場、持つ人、役、期限、なくした時、漏れた時を書きます。値らしい物を貼ると断られます。回す周期は欄に無いので、足した後に `inventory.toml` をエディタで開いて `rotate_days` を書きます。
