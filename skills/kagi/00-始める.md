# 00 始める

## 入れる

digitaldoor のリポジトリの最上位で、kagi を編集できる形で入れます。

```bash
.venv/bin/pip install -e kagi
```

机の画面(08)も使う時は `.venv/bin/pip install -e 'kagi[app]'` です(`flet` が入ります)。本体は標準ライブラリだけで動きます。

入れていない時は、`kagi/` の中で `python3 -m kagi` と打っても同じに動きます。リポジトリの最上位で `python3 -m kagi` と打つと、最上位の `kagi/` の置き場が先に見つかって動かないことがあるので、`kagi` の命令を使うか、`kagi/` の中で打ちます。

## 作業の場所を作る

```bash
kagi init --dir ~/kagi-data
```

`inventory.toml`(在庫表)、`ports.toml`(口の表)、`machines.toml`(機械の表と鍵の表)、`audit.log`(記録)ができます。どれも素の文字で、エディタで開けます。

作業の場所には、機械の名、番地、指紋、アカウントの名が入ります。公開するリポジトリの外に置きます。
