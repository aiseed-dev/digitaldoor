# 06 鍵を足す、回す、外す(認証と鍵はひと組)

```bash
kagi key list
```

鍵ごとに、持つ人、指紋、入れてよいサーバー、在庫表の期限が出ます。在庫表(`inventory.toml`)に同じ id が無い鍵は「無い(K-14)」と出ます。

## 足す

鍵は人が作ります。

```bash
ssh-keygen -t ed25519 -a 64
```

パスフレーズを付けます。持ち歩く物は `-t ed25519-sk` で物の鍵(FIDO2 のセキュリティキー)にします。

1. `machines.toml` の `[[key]]` に一件、サーバーの `keys` に id を足します。
2. 在庫表に同じ id で一件(置き場、期限、回す周期)を足します。
3. サーバーへは `ssh-copy-id -i 新しい.pub <サーバー>` で入れます。
4. `collect` と `check` で「表に無い鍵」が出ない事を見ます。

## 回す

1. 新しい鍵を足します(上の手順)。
2. 新しい鍵で入れる事を確かめます。
3. サーバーの `authorized_keys` から古い行を消します。
4. 表の `keys` と `[[key]]` から古い id を外します。
5. `check` を走らせます。
6. 古い鍵のファイルを消し、在庫表の行に消した日を書きます。

## 外す(人が辞めた、コンピューターを無くした)

1. その人の鍵の id を、全部のサーバーの `keys` から外し、`users` と `admins` からも外します。
2. `kagi machine check`(全部のサーバー)を走らせると、どのサーバーに残っているかが「表に無い鍵」「表に無いアカウント」として出ます。
3. `fix` の手で一台ずつ直します。

どれも、終わったら `kagi log add --action key.add`(`key.rotate`、`key.remove`)を一行足します。

## アプリに出した token の台帳

アプリの門に入る token(アプリが相手ごとに出す物)は別の台帳で、`kagi check tokens` で見ます。台帳の既定の場所は `~/.config/aiseed/tokens.json` で、`--file` で別の場所を指せます。誰に、どの範囲で、いつまで出したかが出ます。期限切れのまま取り消していない物は「直す」です。出す・取り消すは、そのアプリの命令でします。台帳がサーバーのアプリ専用のアカウントの持ち物の時は、そのアカウントで読む命令になり、打つのは人です。

台帳の形は seed のサーバー(https://github.com/aiseed-dev/seed )の `seed token` に合わせてあります。机の画面では「鍵」の下に並びます。
