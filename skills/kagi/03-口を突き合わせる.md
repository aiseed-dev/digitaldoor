# 03 口を突き合わせる

## 口の表と比べる

機械で口の一覧を取り、ファイルにして渡します。kagi は自分で機械に入りません。

```bash
ss -ltnp > /tmp/db1-ss.txt
```

```bash
kagi check ports --host db1 --ss /tmp/db1-ss.txt
```

出るのは三つです。表に無い口、表にあって開いていない口、外向きで表と違う口。表に無い口は、表に足すか、閉じます。

確かめ方: 差が無くなるまで直します。

## Samba の口を見る

Samba の機械の `/etc/samba/smb.conf` を写して渡します。

```bash
kagi check smb --conf smb.conf
```

`include` の先は辿らないので、あればそのファイルも別に渡します。

出る「直す」: SMB1 が通る、署名が任意、ゲストが入れる(`map to guest` と共有ごと)、全部の口に聞く(`interfaces` と `bind interfaces only = yes`)、個人で付けている(`valid users` と `write list` は `@group` で)、`interfaces` に LAN の外を向く項目。

「見るだけ」: `server role`、`passdb backend` の場所、`password` を含む行(中身は出しません)。

確かめ方: 直して `testparm -s` で読めるのを見てから、もう一度走らせて「直す物は無い」まで進めます。`kagi report --smb smb.conf` で、報告の口の節にも載ります。
