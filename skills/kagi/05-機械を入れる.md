# 05 機械を入れる(Debian 13)

```bash
kagi machine install --host newbox
```

`install/newbox/` に三つのファイルができます。`preseed.cfg`(インストーラーへの答え)、`firstboot.sh`(入れた後に一度)、`手順.md`(十二歩)です。あとは `手順.md` の通りに進めます。

- パスワードと盤は `preseed.cfg` に入りません。インストーラーが尋ねた時に、人が画面で打つ・選びます。
- root は止まり、最初の管理者(`admins` の先頭)が sudo を持ちます。ssh は表の鍵でだけ入れます。
- `admins` か `keys` が無い機械、弱い鍵(RSA 2048 未満)、Debian 13 でない機械には、ファイルを書きません。
- **本物のインストーラーではまだ通していません。** 初めての時は、消してよい機械か仮想の機械で試します。
