# 02 記録を始める

## 署名の鍵を置く

記録の署名に使う鍵を一つ作って置きます。kagi は鍵を作りません。人が自分の端末で打ちます。

```bash
install -d -m 700 ~/.config/kagi
head -c 32 /dev/urandom > ~/.config/kagi/log-key
chmod 600 ~/.config/kagi/log-key
export KAGI_LOG_KEY_FILE=~/.config/kagi/log-key
```

`export` は打ったターミナルにだけ効きます。kagi は環境変数だけを見るので、もう動いている Claude Code や別のターミナルには届きません。毎回効かせる時は `~/.bashrc` に同じ一行を足し、Claude Code を開き直します。systemd で動かす時は、credential の `kagi-log-key`(`$CREDENTIALS_DIRECTORY/kagi-log-key`)を先に探します。

この鍵も在庫表に一件書きます(置き場 `pc:~/.config/kagi/log-key`、役「kagi の記録の署名」)。

## 一行足す

鍵を使った事、在庫表を変えた事、口を変えた事は、その時に一行足します。

```bash
kagi log add --actor suzuki --action inventory.add --detail web1-app-env
```

## 確かめ方

`kagi log verify` が `ok` を出します。試しに `audit.log` を写して一行消し、写しで `verify` が落ちる事を一度見ておきます。

記録は追記だけです。間違えた行は消さず、直した事を新しい行として足します。
