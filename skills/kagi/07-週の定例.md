# 07 週の定例

```bash
kagi weekly
```

機械の表の全部の機械の写しを取り直し、在庫、機械(前の写しから増えた・消えた直す物)、出した token、記録を一枚にして、作業の場所の `weekly-<日>.md` に書きます。入れなかった機械は、その事が末尾に出ます。先週の紙と並べて読みます。

増えた直す物は、見張りの「検知」として扱います。誰が受け、何日以内に何をするかの決め方は `skills/detection/` の 06 と 07 にあります。

良い形の出どころは、連載「Claude と一緒に育てる Debian サーバー」(https://aiseed.dev/debian-server/ )の第 11 章「週 15 分」の定例です。どの章がどの行に当たるかは `kagi/docs/設計書.md` §3.4b にあります。直し方が分からない行は、その章を読むか、行をそのまま Claude に渡します(行には値も番地も入りません)。
