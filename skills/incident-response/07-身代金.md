# 07 身代金を求められた時

## この章で読むこと

ランサムウェアの画面、またはデータを公開すると脅す連絡で、金銭(暗号資産を含む)を求められた時です。

**払うかどうかを決めるのは、経営者です。** Claude に決めさせません。Claude は、払う手順、相手との交渉の文、暗号資産の送り方を書きません。Claude がするのは、決めるための事実を並べること、公的な資料が何と言っているかを出典つきで示すこと、相談先を示すことです。

## 最初にする事

1. **相手に返事をしない。** 要求の文にある連絡先へ、まだ連絡しません。連絡するかも経営者が決めます。
2. **要求の文を残す。** 画面の写真、ランサムノートのファイル(消さない、開いて保存し直さない)、脅しのメール(転送せず、そのまま残す)。期限と金額と連絡先を、記録に書き写します(01)。
3. **01 と 02 を進める。** ネットワークから外す、コピーを取る、止める。身代金の話と並べて、手を止めずに進めます。
4. **警察に通報・相談する。** 05 の「警察」。
5. **保険の会社に連絡する。** サイバー保険の契約がある時は、契約に書かれた通知の期限と手順に従います(00、05)。

## 公的な資料が言っている事

### 警察庁(`sources.md` 10)

- 暗号化されたデータを戻す対価として求められる金銭等を払うことについて、警察は被害者に、「犯罪グループ等の活動資金となることが懸念される」こと、「暗号化されたデータの復号が保証されるわけではない」ことを説明している、と書いています。
- 払ったかどうかを含む、被害の情報の提供と、捜査への協力を求めています。
- ランサムウェアの被害に遭った時は、最寄りの警察署かサイバー犯罪相談窓口に通報・相談するよう求め、初動の支援や復号の道具の案内ができる場合がある、としています。
- 一部のランサムウェアには、No More Ransom のプロジェクトで復号の道具が公開されていること、警察庁が開発した復号の道具(LockBit、Phobos/8Base の物)を広報したことを書いています。道具が使えるかは、ランサムノートと暗号化されたファイルの拡張子で調べます。

### JPCERT/CC(`sources.md` 14)

- 「侵入型ランサムウェア攻撃を受けたら読む FAQ」(2026-06-18 更新)で、身代金は支払うべきではない、という立場を書いています。理由として、ファイルが戻る保証が無いこと、被害の原因が解消されないこと、払った後に別の攻撃や追加の要求を受けるおそれがあることを挙げています。

### 警察庁の情勢(`sources.md` 11)

- 令和 7 年上半期のランサムウェアの被害の報告は 116 件で、半期として令和 4 年下半期と並んで最多。中小企業が 77 件で約 3 分の 2 を占めました。
- 被害に遭った組織への質問の結果では、調査と復旧に 1,000 万円以上かかった組織の割合が、令和 6 年の 50% から 59% に増えました。
- 攻撃者は、休みの前の金曜日の終業後に入り、月曜日の朝までに暗号化する、入口を閉じられても入り直せるよう遠隔で操作できる道具を置く、痕跡を消し復旧させないためにログと控えを消す、などをしている、と書いています。

## 経営者が決めるための表

Claude は、次の表を事実で埋める手伝いをします。払うか払わないかの欄は作りません。

| 問い | 事実 | 出どころ |
|---|---|---|
| 控えから戻せるか。どこまで、何日で | | 04 の「控えが無事かを確かめる」 |
| 復号の道具が使えるか | | No More Ransom、警察への相談 |
| データが盗まれたか(二重の脅し) | | 03 |
| 盗まれたデータに個人データが含まれるか。何人分か | | 03、05 |
| 業務が止まっている範囲と、止まり続けた時の影響 | | 02 の「止めると仕事が止まる物」 |
| 法の報告の期限 | | 05、01 の歩 6 |
| 保険の契約が、身代金と調査と復旧の費用をどう扱うか | | 保険の約款、保険の会社の答え |
| 警察の助言 | | 警察への相談の記録 |
| 弁護士の助言 | | |

払うことについて、法の面(相手が制裁の対象か、払うことが他の法に触れないか)は、このガイドでは確かめていません。弁護士に確かめます。

## 相談先

- 警察: 最寄りの警察署、都道府県警察のサイバー犯罪相談窓口(05、`sources.md` 9)。
- JPCERT/CC: 初動の対応の支援など(05、`sources.md` 13)。
- IPA 情報セキュリティ安心相談窓口: 技術的な相談(05、`sources.md` 9)。
- 事故の調査を頼める会社、弁護士、保険の会社: 00 の連絡先の表。

## 記録

決めた事は、誰が、いつ、何の事実をもとに決めたかを、記録に追記します(06)。警察庁は、払ったかどうかを含む情報の提供を求めています。

```
## 身代金の要求  <日付 時刻>
- 要求の受け取り方(画面、メール、電話):
- 金額 / 期限 / 連絡先(要求の文のコピーの場所):
- データの公開の脅しの有無:
- 警察への通報・相談: <日時、相手>
- 保険の会社への連絡: <日時、相手、答え>
- 経営者の決定: <日時、決めた事、もとにした事実(上の表)>
```

## 確かめていない事

- 身代金を払うことに関わる、日本と外国の法の制限(制裁の対象への支払いなど)は確かめていません。
- サイバー保険の一般の扱いは、保険の会社と契約ごとに違うので書いていません。
