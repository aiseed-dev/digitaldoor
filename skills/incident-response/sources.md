## 1. Anthropic「Cyber Verification Program」(ヘルプの記事、2026-10-06 更新)

- https://support.claude.com/en/articles/14604842-cyber-verification-program
- 運営から渡された記事の写しで読みました。公開の URL は上のとおりです。確かめた事: 三つの枠(Defense Access、Red Team Access、Specialized Access)。Defense Access の「できること」に incident response が入ること。毎日の安全な開発と警報の切り分けは一般のモデルでできること。CVP に入った者は全員データの保持が必須で、悪用の見張りのためであること。ZDR は保持の免除を持つ組織の社内の用途だけであること。既定では社内の用途だけで、客への仕事は別の承認が要ること。Defense Access に要る多要素認証と 7 日ごとの API の鍵の入れ替え、2026-12-15 からのフィッシングに強い多要素認証と長く使う API の鍵の不可。

## 10. 警察庁「ランサムウェア被害防止対策」

- https://www.npa.go.jp/bureau/cyber/countermeasures/ransom.html
- 確かめた事: 網から隔離し、電源は落とさない。警察署かサイバー犯罪相談窓口への通報・相談、初動の支援と復号の道具の案内。支払いについての警察の説明(活動資金となる懸念、復号の保証が無い)と、支払いの有無を含む情報提供の依頼。よくある質問(公表は求めない、復旧に配慮、提供を頼む物の例、軽い事案も)。侵入経路と範囲の調査、VPN 機器の脆弱性、パスワードの変更。No More Ransom と警察庁開発の復号の道具。バックアップをこまめに取り網から切り離す、ログを取る、訓練。

## 11. 警察庁サイバー警察局「令和 7 年上半期におけるサイバー空間をめぐる脅威の情勢等について」(令和 7 年 9 月)
