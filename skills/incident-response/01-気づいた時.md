# 01 気づいた時(最初の一時間)

## 最初に: 時計はもう回っています

個人情報の漏えい等の報告の期限は、**会社のいずれかの部署が事態を知った時**から数えます。速報の目安は概ね 3〜5 日以内、確報は 30 日以内(不正の目的のおそれがある時は 60 日以内)です(個人情報保護委員会 ガイドライン通則編 3-5-3-3、3-5-3-4。規則第 8 条。詳しくは 05)。特別社会基盤事業者には、別の法の報告の期限もあります(05)。

だから、この章の歩 1 で時刻を書き、歩 6 で期限の日を書きます。報告が要るかどうかはまだ分からなくてかまいません。分からないまま、日だけ先に書きます。

## この章で読むこと

最初の一時間にする事は、六つです。直すことは、まだしません。

```
歩 1 時刻を書く
歩 2 見た事を、見たまま書く
歩 3 広がりを止める(ネットワークから外すか、電源を切るか)
歩 4 コピーを取る
歩 5 一人で決めない(連絡する)
歩 6 期限の日を書く
```

Claude は、歩ごとに、聞く事と書く事を人に示します。人が慌てている時は、一度に一つだけ聞きます。

## 歩 1 時刻を書く

- 人: 今の時刻を、記録の置き場(00)の `00-時刻と見た事.md` の一行目に書きます。
- 人か Claude: 見ているコンピューターの時刻と、正しい時刻との差を書きます。差は、03 で記録の時刻を揃える時に使います。

```
[読む] Linux
date '+%Y-%m-%d %H:%M:%S %z'      # コンピューターの時刻(地方時)
date -u '+%Y-%m-%d %H:%M:%S'      # コンピューターの時刻(協定世界時)
timedatectl                       # 時刻の合わせ方と、合っているか

[読む] Windows (PowerShell)
Get-Date -Format 'yyyy-MM-dd HH:mm:ss zzz'
(Get-Date).ToUniversalTime().ToString('yyyy-MM-dd HH:mm:ss')
w32tm /query /status              # 時刻の源と、最後に合わせた時
```

正しい時刻は、スマートフォンの時計か、電話の時報で取ります。

- 確かめ: 記録の一行目に、「知った時刻」「誰が知ったか」「コンピューターの時刻と正しい時刻の差」の三つがある。

## 歩 2 見た事を、見たまま書く

最初に気づいた人から、その人の言葉で聞きます。解釈を足さずに書きます。「ウイルスだと思う」は「(本人の推測)」と印をつけて分けます。

聞く事:

1. 何を見たか。画面の文、出た窓、届いたメール、外からの連絡の文。
2. いつ見たか。何をしている時か。
3. どのコンピューターか(名前、置き場所、使っている人)。
4. 見た後に、何をしたか(閉じた、再起動した、ファイルを開いた、誰かに転送した)。
5. 同じ物を見た人が他にいるか。

画面に出ている物は、**別のコンピューター(スマートフォン)で写真に撮ります**。画面のコピーを、そのコンピューターの上で撮って保存すると、そのコンピューターのディスクに書き込みます。

### 時刻と見た事の様式

```
# 時刻と見た事  事故 <2026-11-11-001>

知った時刻(正しい時刻): <2026-11-11 09:12>
知った人 / 部署: <>
コンピューターの時刻との差: <コンピューターが 2 分進んでいる>

## 見た事(本人の言葉のまま)
- <09:05 頃、共有フォルダのファイルの名前の末尾が見慣れない文字に変わっていた>
- <デスクトップに「README」という文書が出ていた>

## 本人がした事
- <ファイルを一つ開こうとして開けなかった。再起動はしていない>

## 本人の推測(分けて書く)
- <ランサムウェアだと思う>

## 写真
- <スマートフォンで画面を 3 枚。ファイル名と撮った時刻>

## 追記(書き直さず、下に足す)
- <09:30 追記: …>
```

記録は追記だけです。間違えたら、消さずに「<時刻> 訂正: 前の行の … は … だった」と下に書きます(06)。

- 確かめ: 見た事と推測が、別の見出しに分かれている。

## 歩 3 広がりを止める

広がりを止める手は二つあります。ネットワークから外すことと、電源を切ることです。どちらも、止める権限を持つ人(00)が決めます。連絡が取れない時の扱いも 00 で決めてあります。

### ネットワークから外す

警察庁は、ランサムウェアに感染した PC などを、LAN の線を抜く、無線を切るなどしてネットワークから離し、ログ等が消えることがあるので電源は落とさないよう求めています(`sources.md` 10)。

- 人(読んで確かめてから): LAN の線を抜く。無線を切る(コンピューターの無線の切り替え、または無線 LAN の機器の側でそのコンピューターを外す)。
- 抜いた線には、どのコンピューターの線かの札をつけます。
- 抜いた時刻を記録に書きます。

外すのを一台にするか、ネットワーク全体(回線)にするかは、次の事実で決めます。

| 事実 | 寄る方 |
|---|---|
| 一台だけで起きている。他のコンピューターのファイルは変わっていない | その一台だけを外す |
| 共有のフォルダやサーバーのファイルが、今も次々に変わっている | 変わっているサーバーと、そこへ書いているコンピューターを外す。分からなければネットワーク全体 |
| 外へ大きな通信が続いている(防火壁やルーターの画面で見える) | 回線を外す。外す前に、その画面を写真に撮る |
| 業者の遠隔の道具で入られた形跡がある | その道具のアクセス経路を閉じる(02)。分からなければ回線 |
| 分からない | 止める権限を持つ人が決める。決めるまでの間、見た事を書き続ける |

ネットワーク全体を外すと、メール、電話(ネットワークの電話の場合)、クラウドの仕事も止まります。連絡の手段を先に確かめてから外します(00 の連絡先の表の「会社の外の連絡の手段」)。

### 電源を切るか

電源を切ると、メモリの中にある物(動いているプログラム、繋がっている相手、開いている鍵)が消えます。調べる手がかりが減ります。だから、**ネットワークから外すことを先にし、電源は入れたまま**にするのが、公的な資料の勧める形です(`sources.md` 10、14)。

電源を切ることを考えるのは、次のような事実がある時です。決めるのは止める権限を持つ人で、決めた理由を記録に書きます。

- ネットワークから外した後も、そのコンピューターの中でファイルの暗号化が進んでいるのが見えている(ファイルの名が次々に変わっていく)。
- コンピューターが、人の安全に関わる物を動かしていて、そのまま動かすと危ない。

切る時は、切る前に画面を写真に撮り、切った時刻と切り方(普通の終了か、電源の線を抜いたか)を書きます。

### 触らない物

- 身代金の要求の文書(ランサムノート)。開いた画面を写真に撮り、ファイルは消さずに置きます。警察が提供を求める物の一つです(`sources.md` 10)。
- 暗号化されたファイル。後で復号の道具が出ることがあるので、消さずに置きます(`sources.md` 14)。
- 怪しいファイル、メールの添付。開かない、消さない、他のコンピューターへ送らない。マルウェアの検体の解析は、このガイドでは扱いません。
- 記録のファイル。消さない、開いて保存し直さない。
- ウイルス対策の道具の「駆除」や「隔離」の操作。押す前に、画面の検出の名と、ファイルの場所を写真に撮ります。押すかどうかは止める権限を持つ人が決めます。
- 再起動と、更新を当てること。どちらも、03 と 04 まで待ちます。

- 確かめ: 外したコンピューターの一覧(名前、外した時刻、外し方、電源の状態)が記録にある。

## 歩 4 コピーを取る

直す前に、今の状態のコピーを取ります。コピーは、外付けの記憶装置(00 で用意した物)に書きます。事故の起きたコンピューターのディスクには書きません。

### 何が取れて、何が要るか

| コピー | 何が分かるか | 何が要るか | 誰ができるか |
|---|---|---|---|
| 画面の写真 | 出ていた文、時刻 | スマートフォン | 誰でも |
| 動いているプログラム、繋がっている相手の一覧(下の命令) | その時に動いていた物、外の相手 | 管理者の権限、外付けの記憶装置 | 係 |
| 記録のファイルのコピー(下の命令) | 誰が、いつ、どこから | 管理者の権限、外付けの記憶装置 | 係 |
| メモリのコピー | 動いていた物の中身、鍵 | 前もって用意し試した取得の道具、メモリの大きさ以上の記憶装置 | 前もって練習した係、または調査の会社 |
| ディスクのコピー(イメージ) | 消されたファイル、全部の履歴 | 別の起動の手段と、書き込みを防ぐ機器、ディスク以上の大きさの記憶装置 | 調査の会社。警察に通報する時は、警察とも相談 |

メモリのコピーとディスクのコピーは、道具を前もって用意し、練習していないと、取ろうとしてコンピューターを変えてしまいます。用意が無い時は、上の三行(写真、一覧、記録のコピー)まで取り、残りは 00 の「事故の調査を頼める会社」か警察に相談します。警察は、通報した時の提供物の例として、ランサムノート、通信ログ、ディスクイメージ、メモリダンプ、システム構成図を挙げています(`sources.md` 10)。

### 一覧をコピーする命令

外付けの記憶装置を `/media/<外>/`(Linux)か `E:\`(Windows)として書きます。差した記憶装置の名を確かめてから打ちます。

```
[コピー] Linux(root で。出力は外の記憶装置へ)
D=/media/<外>/jiko/<2026-11-11-001>/utsushi/<コンピューター>
mkdir -p "$D"
date -u '+%F %T UTC' > "$D/00-date.txt"
uptime            > "$D/01-uptime.txt"
who -a            > "$D/02-who.txt"
last -F -n 200    > "$D/03-last.txt"
ps auxwwf         > "$D/04-ps.txt"
ss -tunap         > "$D/05-ss.txt"
ip addr; ip route > "$D/06-ip.txt" 2>&1
systemctl list-units --type=service --state=running > "$D/07-services.txt"
systemctl list-timers --all > "$D/08-timers.txt"
ls -la /etc/cron.* /var/spool/cron/crontabs > "$D/09-cron.txt" 2>&1
getent passwd     > "$D/10-passwd.txt"
```

```
[コピー] Windows(PowerShell を管理者で。出力は外の記憶装置へ)
$D = "E:\jiko\<2026-11-11-001>\utsushi\$env:COMPUTERNAME"
New-Item -ItemType Directory -Force $D | Out-Null
(Get-Date).ToUniversalTime().ToString('u') | Out-File "$D\00-date.txt"
quser 2>&1 | Out-File "$D\01-quser.txt"
Get-CimInstance Win32_Process |
  Select-Object ProcessId,ParentProcessId,Name,CreationDate,CommandLine |
  Export-Csv "$D\02-process.csv" -NoTypeInformation -Encoding UTF8
Get-NetTCPConnection |
  Select-Object LocalAddress,LocalPort,RemoteAddress,RemotePort,State,OwningProcess,CreationTime |
  Export-Csv "$D\03-tcp.csv" -NoTypeInformation -Encoding UTF8
ipconfig /all | Out-File "$D\04-ipconfig.txt"
Get-Service | Where-Object Status -eq Running |
  Select-Object Name,DisplayName | Export-Csv "$D\05-services.csv" -NoTypeInformation -Encoding UTF8
Get-ScheduledTask | Where-Object State -ne Disabled |
  Select-Object TaskPath,TaskName,State | Export-Csv "$D\06-tasks.csv" -NoTypeInformation -Encoding UTF8
Get-LocalUser | Select-Object Name,Enabled,LastLogon |
  Export-Csv "$D\07-localusers.csv" -NoTypeInformation -Encoding UTF8
Get-LocalGroupMember Administrators | Out-File "$D\08-admins.txt"
```

### 記録のファイルをコピーする命令

```
[コピー] Linux(root で)
D=/media/<外>/jiko/<2026-11-11-001>/utsushi/<コンピューター>
journalctl --since '<2026-11-01>' -o short-iso-precise > "$D/20-journal.txt"
cp -a /var/log "$D/var-log"        # 元の時刻を保ってコピーする

[コピー] Windows(管理者で)
$D = "E:\jiko\<2026-11-11-001>\utsushi\$env:COMPUTERNAME"
wevtutil epl Security "$D\Security.evtx"
wevtutil epl System   "$D\System.evtx"
wevtutil epl Application "$D\Application.evtx"
wevtutil epl Microsoft-Windows-TerminalServices-LocalSessionManager/Operational "$D\TS-LSM.evtx"
wevtutil epl Microsoft-Windows-PowerShell/Operational "$D\PowerShell.evtx"
```

`wevtutil epl` は記録を別のファイルに書き出す命令で、元の記録は変えません。書き出した物は 03 で読みます。

### コピーの一覧を作る

コピーした物ごとに sha256 を取り、一覧にします。後で「コピーは変わっていない」と示すためです。

```
[読む] Linux
cd /media/<外>/jiko/<2026-11-11-001>/utsushi
find . -type f -exec sha256sum {} + > ../utsushi-sha256.txt

[読む] Windows
Get-ChildItem -Recurse -File E:\jiko\<2026-11-11-001>\utsushi |
  Get-FileHash -Algorithm SHA256 |
  Export-Csv E:\jiko\<2026-11-11-001>\utsushi-sha256.csv -NoTypeInformation -Encoding UTF8
```

- 確かめ: コピーの一覧に、コピーした物、コピーした時刻、コピーした人、sha256 がある。

## 歩 5 一人で決めない

この時点で、00 の連絡先の表の順に連絡します。

- 止める権限を持つ人に、歩 2 と歩 3 で書いた事を、そのまま読み上げます。
- 個人情報の責任者に、「個人データの漏えい等の可能性がある」と知らせます。報告が要るかを決めるのはこの人と経営者です(05)。
- 業者の道から入られた形跡があれば、その業者に知らせます。業者が自分の側で何かを消したり直したりする前に、コピーを取ってもらうよう頼みます。

連絡は、事故が起きているかもしれないメールやチャットを避け、電話か、00 で決めた会社の外の手段で行います。連絡した時刻、相手、伝えた事、相手の答えを、記録に追記します。

通知の文の雛形(社内、最初の一報):

```
件名: 【至急】情報システムの事故の可能性(第 1 報)

<時刻> に、<部署> の <役> が <コンピューター> で <見た事> を確認しました。
今わかっている事: <見た事だけ>
したこと: <ネットワークから外したコンピューター / 時刻>
まだわかっていない事: 原因、範囲、個人データへの影響
お願い: <コンピューター> に触らないでください。再起動、ファイルの削除、
ウイルス対策の操作をしないでください。気づいた事は <係> に電話で。
次の連絡: <時刻> に第 2 報を出します。
```

## 歩 6 期限の日を書く

05 の「最初の日に見る表」を開き、当たるかもしれない報告ごとに、期限の日を書きます。当たるかどうかが分からない物も、分からないまま書きます。

```
## 期限(当たるかは未定。05 を見て判断する)
知った日: <2026-11-11>(1 日目)
- 個人情報保護委員会への速報: 概ね 3〜5 日以内の目安 → <11-13〜11-15>
- 確報 30 日以内 → <12-10> / 不正の目的のおそれの時 60 日以内 → <2027-01-09>
  (末日が土日・祝日・年末年始の閉庁日なら翌日。ガイドライン 3-5-3-4)
- 委託元への通知(委託を受けている時): 速やかに。目安は概ね 3〜5 日以内
- 契約の通知: <契約の名> <契約の期限>
- 保険の通知: <約款の期限>
```

日付の数え方は、知った日を 1 日目にし、土日と祝日も数えます(ガイドライン 3-5-3-4 の注)。Claude は、暦を見て日を数え、人が確かめます。

- 確かめ: 記録に、期限の日の表がある。決める人(個人情報の責任者、経営者)に、表を渡した時刻が書いてある。

## 一時間の後

ここまでで、広がりは止まりかけ、コピーがあり、決める人に伝わっています。次は 02(止める)です。止める手は、コピーを取った後にします。

## 確かめていない事

- 命令の例は、Debian 系と Windows 10/11 を考えて書きました。全部を実機では通していません。
- メモリのコピーの道具の選び方と使い方は、このガイドでは書いていません。道具を前もって選び、練習の記録を 00 に残す形を考えています。
