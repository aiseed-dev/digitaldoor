# 05 試す

決まりは、書いただけでは鳴るか分かりません。記録が届いていない、欄の名が違う、時間帯がずれている、のどれでも黙ったままになります。決まりを一つ書いたら、わざと起こして鳴るかを見ます。

## 試す場所と、試さない事

- **試すのは試験用の環境です。** 本番と同じ形の試験用の機械か、本番の中で試しても害の無い物だけを使います。試す前に、01 の一覧の「誰の許しで」の人に、何を、いつ、どの機械で試すかを伝えます。
- **害の無いやり方だけを使います。** 自分のアカウントで、自分の手で、正しい道具で起こします。
- **攻撃の手順を本番で試しません。** 他人のアカウントを当てる、弱いところを突く、侵入の道具を動かす事は、この手引きの外です。侵入の試験は Cyber Verification Program の Red Team Access の枠で、試験の会社か社内の専門の組が、許しを得て行う仕事です(`sources.md`)。
- **試した事を記録に残します。** 試しで鳴った知らせが、本物と取り違えられないように、試す前に受ける人(06)に「何時から何時まで試す」と伝え、kagi の記録にも一行足します。

```bash
kagi log add --actor suzuki --action detection.test --detail "DT-03 を web1 で試す 14:00-14:15"
```

## 試しの例

| 決まり | 起こし方(害の無い物) | 見る物 |
|---|---|---|
| 1 夜中の管理者のログイン | 試験用の機械で、`off_hours.py` の `--start` と `--end` を今の時刻が外れるように変えて走らせる。時計を変えて試さない | 自分の今日のログインが一行出る |
| 3 失敗が続いた後の成功 | 試験用の機械に、自分のアカウントで、わざとパスワードを 5 回誤ってから正しく入る(パスワードで入れる試験用の機械だけ。本番の SSH は鍵だけにしておく) | `fail_then_ok.py` が一行出す |
| 4 新しい管理者 | 試験用の機械で、試しのアカウントを作り、管理者の組に足し、終わったら消す | 作成と追加の記録が届き、鳴る。消した記録も届く |
| 5 表に無い口 | 試験用の機械で、`python3 -m http.server 8099 --bind 127.0.0.1` を一つ開き、終わったら Ctrl-C で閉じる | `kagi check ports` に「表に無い口」が出る |
| 6 表に無い鍵 | 試験用の機械の試しのアカウントの `authorized_keys` に、試しに作った鍵を一本足し、終わったら消す | `kagi machine check` に「表に無い鍵」が出る |
| 7 控えが取れていない | 試験用の機械で、控えの timer を一度止め、決めた時間の後に戻す | 鳴る。戻した後に止む |
| 8 記録が途切れた | 試験用の機械の記録の転送を一度止め、決めた時間の後に戻す | 鳴る。戻した後に止む |
| 12 sudo の失敗 | 自分のアカウントで、sudo のパスワードをわざと一度誤る | 記録に一行出る |
| 13 居ないアカウント | 試験用の機械に、居ない名前で一度 SSH を試す(`ssh no-such-user@試験用の機械`) | `Invalid user` の行が一行増える |

どの起こし方も、終わったら元に戻します。戻した事も記録に一行足します。機械を変える手(アカウントを作る、timer を止める)は、AI が文で出し、人が読んで打ちます。

## 鳴らなかった時に見る所

1. **記録が出ているか。** 起こした機械の上で、記録に行が出ているか(`journalctl -n 20` など)。出ていなければ、監査の設定か、記録の出し方の問題です。
2. **記録が届いているか。** 記録の機械に、その行が届いているか。届いていなければ、転送(02)の問題です。
3. **時刻が合っているか。** 機械と記録の機械の時計、UTC と日本時間の取り違え。
4. **決まりの文が合っているか。** 欄の名、文の形(「Failed password」と「Failed publickey」の違いなど)、大文字と小文字。

## 試しの記録の雛形

| 日 | 決まり | 機械 | 起こした事 | 鳴ったか | 鳴るまでの時間 | 直した事 | 試した人 |
|---|---|---|---|---|---|---|---|
| 2026-11-xx | DT-03 | 試験用の機械 | 自分で 5 回誤って入った | 鳴った | 2 分 | 無し | (会社が書く) |

試した日を 01 と 04 の表にも書きます。試していない決まりは「試していない」と残します。
