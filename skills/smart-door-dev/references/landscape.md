# 規格団体と制度の地図(2026年10月17日に確かめた)

日付と数字は変わります。製品の判断に使う前に、各団体の頁で新しさを確かめてください。詳しい解説と出典は、サイトの解説 06「スマートドアとスマートロックを作る人が集まる場所」と解説 07「日本のスマートドアとスマートロックの現状」(https://door.aiseed.dev/guide/)にあります。

## 規格

| 規格 | 誰が | 扉で使う所 | 入手 |
|---|---|---|---|
| Matter | CSA | 錠(Door Lock、1.0 から)。1.5(2025年11月)でカメラと開閉機器、1.6(2026年6月17日)で NFC による設定と複数エコシステムの共同管理 | 確定した仕様は CSA の頁から無料。SDK(connectedhomeip)は Apache-2.0。草案と作業部会は Participant(年21,500ドル)以上 |
| Aliro 1.0 | CSA | スマートフォンとウォッチの鍵。NFC、Bluetooth LE、Bluetooth LE と UWB。2026年2月26日公開 | 仕様は CSA の頁から無料。試験の道具と模擬の装置が GitHub の aliro-access-control に Apache-2.0 で公開。認証は CSA が認めた試験所 |
| OSDP | SIA | 読取機と制御盤の間。IEC 60839-11-5 | 実装に libosdp(Apache-2.0)。適合確認は SIA の会員 |
| ONVIF Profile C、A | ONVIF | 扉の監視と制御、資格情報と規則 | 会員制 |
| ECHONET Lite | エコーネットコンソーシアム | 電気錠の機器の種類(クラスコード 0x026F) | 仕様は公開 |
| JEM-A(JEM1427) | 日本電機工業会 | インターホンと電気錠の連動の接点 | 公開の本文は見つからない。各社の取扱説明書に極性と配線の制限 |

扉のコントローラの層(火災、停電、避難のときの挙動、改ざんの分かる監査記録)を扱う公開の規格は見つかっていません。digitaldoor の扉コントローラ仕様書が、その空いた所を扱います。

## 制度

| 制度 | 地域と時期 | 錠を作る人がすること |
|---|---|---|
| JC-STAR | 日本。2025年3月に★1の申請の受付開始 | IoT 製品の最低限のセキュリティの適合ラベル。錠では2025年に住宅用の電気錠が★1を受けた例がある |
| 無線機器指令の委任規則(2022/30)と EN 18031 | EU。2025年8月1日から義務 | 無線でつながる機器の、パスワード、更新、データ保護 |
| サイバーレジリエンス法(CRA) | EU。報告の義務は2026年9月11日から、全面の適用は2027年12月11日 | スマートドアロックは重要な製品の区分に入るとされる。脆弱性の報告の手順と更新の期間を用意する |
| PSTI 法 | 英国。2024年4月29日 | 共通の初期パスワードの禁止、脆弱性の連絡先と更新期間の公開 |
| 建築基準法施行令第125条の2と各地の消防の基準 | 日本 | 屋外への出口は屋内から鍵なしで開けられること。電気錠の火災時の解錠は各地の基準(例: 名古屋市の「電気錠の指導基準」は、型ごとに遠隔の解錠と火災報知に連動した解錠を求める) |

どの制度も、脆弱性の連絡先、更新の期間、初期パスワードの扱いを求める方向です。設計の初めから、更新の仕組み(署名つきの更新)と、連絡先を決めておきます。
