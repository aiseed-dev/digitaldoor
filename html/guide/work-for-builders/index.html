家を建てる会社と工務店に、新しい仕事が生まれる

スマートフォンの鍵で開く扉は、設計、据付、引き渡し、住んでいる間、住む人が替わる時のそれぞれに、現場の仕事を作る

2026.11.15

玄関の扉が、スマートフォンのウォレットの鍵で開くようになると、家を建てる仕事の中身が変わります。鍵と、鍵を配る仕組みは、Apple と Google と規格の団体(CSA)が作ります。家を建てる会社や工務店が新しく作る物はありません。増えるのは、現場の仕事です。付ける、線を通す、つなぐ、確かめる、引き渡す、直す、替える。人に残るのは現場 に書いた事が、玄関でも起こります。

この記事は、家を建てる会社、工務店、リフォームの店の人に向けて、設計から住む人が替わる時まで、段ごとに仕事を並べます。この記事は戸建ての家と、小さな事務所や店の扉を扱います。事実として書くのは、ほかの解説に出典を付けて書いてある事と、電気の工事の資格について法令の条文で確かめた事だけです。ほかの解説の事実は、その解説にリンクでつなぎます。それ以外は、このサイトの考えです。規格の中身は Matterとは何か と Aliroとは何か にあります。

何が変わるか

分かっている事

  • Google は、2026年11月9日付のリリースノートで、Matter と Aliro に対応した戸建て住宅の鍵を、Google Home から Google Wallet に足せるようにしたと書きました(Google Wallet に戸建ての家の鍵が入る)。
  • Apple は、ホームアプリで対応する錠を自分のホームに足すと、ホームキーが自動でウォレットに入り、同じ家の住人にも鍵が入る、と書いています。招待と一員の管理は、家の持ち主がホームアプリで行います(会社に情報を集めるから、流出が起こる の「ウォレットの鍵は、どこに何があるか」)。

戸建ての家では、鍵を出すのも止めるのも住む人です(戸建てと事務所で、スマートフォンの鍵をどう持つか の「戸建ては、ホームアプリで足りる」)。

このサイトの考え

鍵の束を作り、数えて渡す仕事は、住む人のスマートフォンの中に移ります。物として残るのは、扉、錠、ドアホン、電源、線、家のネットワークです。これを付けて、確かめて、直して、替えるのは、その家の近くにいる人です。

[cols="1,3,2"]

段 する事 誰が
設計 玄関まわりの電源と線の通り道、家のネットワークとホームのハブの置き場、扉と錠の選び方を決める 建てる会社、設計の人
据付 付ける、線を通す、つなぐ、確かめる。試しに登録した物を消す 工務店、施工の人
引き渡し 登録の札を渡し、住む人の登録を横で手伝い、一緒に確かめる 施工の人。登録するのは住む人
住んでいる間 連絡を受けて行き、直す、替える 近くの店
住む人が替わる時 前の人の登録を消し、空になった事を確かめ、次の人の登録を手伝う 近くの店。登録するのは次の住む人
今ある家 錠を替える、扉ごと替える、電源の線を足す リフォームの店

設計の段で

ここは、このサイトの考えです。

扉は 20 年、30 年使います。その間に、錠もドアホンも何度か替わります。後から一番手間がかかるのは、機器ではなく、電源と線です。故障も、機器そのものより、電源と配線で起きやすくなります。電池で動く錠は、電池が切れると、切れた事を知らせる事もできません。設計の段で、玄関まわりに電源と線の通り道を用意しておく事が、後の仕事を楽にします。

  • 玄関まわりの電源。 錠、ドアホン、カメラ、明かりのための電源を、扉の近くに取ります。
  • 線の通り道。 扉の枠から壁の中を通る通り道を取り、後から線を足し、引き直せるようにします。
  • 家のネットワーク。 玄関まで無線が届くように、親機の置き場を間取りと一緒に決めます。
  • ホームのハブの置き場。 Apple のホームでは、錠の開け閉めの記録を見るのに Apple TV か HomePod(ホームのハブ)が要り、停電などでハブに届かない時は記録されない事があります(会社に情報を集めるから、流出が起こる の「開け閉めの記録は、どこに残るか」)。ハブは置いたままにする機器なので、置く場所と電源を先に決めます。

電源の取り方と、電気の工事の資格

法令に書いてある事。 2026年11月15日に、e-Gov 法令検索で条文を確かめました。

  • 電気工事士法 第2条第3項は、「電気工事」を、一般用電気工作物等や自家用電気工作物を設置し、変更する工事と定め、政令で定める軽微な工事を除いています。
  • 同じ法律の第3条第2項は、第一種か第二種の電気工事士でなければ、一般用電気工作物等の電気工事の作業に従事できない、と定めています(経済産業省令で定める作業を除きます)。
  • 電気工事士法施行令 第1条は、軽微な工事を挙げています。第1号は、600ボルト以下で使う差込み接続器やソケットなどの接続器、開閉器に、コードやキャブタイヤケーブルをつなぐ工事です。第4号は、電鈴、インターホーン、火災感知器、豆電球などの施設に使う小型変圧器(二次電圧が36ボルト以下の物)の、二次側の配線工事です。
  • 条文に、電子錠の名前はありません。

ここからは、このサイトの考えです。 壁のコンセントを付けるのは電気工事士の仕事で、家を建てる時にやります。錠とドアホンの電源は、コンセントに差す電源で36ボルト以下に落とし、そこから先の、枠と扉までの線を低い電圧にしておきます。こうしておけば、後の交換と線の引き直しは、インターホンの線と同じ扱いに収めやすくなります。設計の段で、玄関の近くにコンセントを一つ取っておく事が、後の仕事を軽くします。ただし、電子錠が施行令 第1条 第4号の「これらに類する施設」に当たるかどうかは、確かめていません。

扉を選ぶ時に見る事は、次の通りです。

[cols="2,3"]

見る事 理由
Matter と Aliro の認証を受けた錠が入るか ウォレットの鍵で開くのは、両方に対応した錠です。認証の確かめ方は Google Wallet に戸建ての家の鍵が入る の「自分で確かめる」にあります
錠の電源は、線か電池か 線なら電池切れが無く、電池なら線の工事が要りません。線の時は、コンセントから取って低い電圧に落とす形かも見ます。電池の時は、替える周期を住む人と決めます
後から別の錠に替えられるか 錠は扉より先に古くなります。扉を外さずに錠だけ替えられる作りを選びます
スマートフォンのほかに開ける道があるか 機械の鍵や暗証番号など。ウォレットの側が止まった時の道です(Google Wallet に戸建ての家の鍵が入る の「発行者の秘密鍵を誰が持つか」)

据付の段で

戸建てと事務所で、スマートフォンの鍵をどう持つか の「戸建ての扉が、工場から家に届くまで」では、据付の人がする事を、配線、ネットワークの区画分け、時刻の設定、試験に使った鍵を消す事、と書きました。建てる側の言葉で言い直すと、次のようになります。ここは、このサイトの考えです。

  1. 付けて、線をつなぐ。 停電の時に設定どおりに動くか、内側から機械で開くかを、実機で試します(人に残るのは現場 の「人に残る仕事」)。
  2. 家のネットワークにつなぐ。 扉の機器は、パソコンや家電とは別の区画に置きます。
  3. 時刻を合わせる。
  4. 試しに登録した物を、全部消す。 動作を確かめるために、店のアプリやスマートフォンで錠を登録する事があります。引き渡しの前に、その登録を全部消します。

最後の手順には、理由があります。一つの錠は、いくつものスマートホームに登録でき、登録した先の数だけ管理者が居ます(Google Wallet に戸建ての家の鍵が入る の「扉のコントローラが鍵を持つか」)。また、Matter の SDK の実装では、登録先を外しても、その登録先が入れた鍵は錠に残ります(戸建てと事務所で、スマートフォンの鍵をどう持つか の「扉を登録した先」)。だから、登録を外すだけで終わらせず、錠を初期化して、誰の登録も無い状態に戻してから引き渡します。

引き渡しの段で

ここは、このサイトの考えです。

物の鍵の束を渡す仕事が、登録を住む人に渡す仕事に変わります。

錠には、登録に使う QR などの登録の番号が付いてきます。この番号は、最初の登録の通り道を張るための物で、扉を開ける鍵そのものではありません(Google Wallet に戸建ての家の鍵が入る の「扉のコントローラが鍵を持つか」)。それでも、錠を自分のホームに登録する入口なので、住む人だけが開けるようにします。

  1. 登録の札は、封をしたまま渡す。 工事の間も、封は開けません。
  2. 住む人が、自分のスマートフォンで登録する。 施工の人は横で手伝い、画面を見て順を伝えます。住む人のスマートフォンは預かりません。
  3. 家族への配り方と、消し方を、一緒にやってみる。 家族に iPhone と Android の人が混ざる時は、両方でやります。
  4. 一緒に確かめる。 終わったら、住む人の画面で、錠が住む人のホームに入っている事と、店のアプリや施工の人のスマートフォンに錠が残っていない事を確かめます。
  5. ほかの開け方と、連絡先を渡す。 機械の鍵などの予備と、困った時に連絡する先を渡します。

住んでいる間

ここは、このサイトの考えです。

ウォレットの鍵では、誰に鍵を配ったかの台帳は住む人のスマートフォンにあり、売った側には名簿が残りません。連絡は、住む人の方から来ます(会社に情報を集めるから、流出が起こる の「売った側は、名簿を持てない」と「それでも、仕事は回る」、扉を作る会社が、ウォレットの鍵を出す会社になるには の「連絡は、利用者の方から来る」)。

鍵がかからない家では、その日のうちに連絡が来ます。だから、近くにいて、すぐ行ける人の仕事になります。要るのは、行ける人と、替えの錠と部品と、依頼を受ける決まった形の伝票です。

直すのは、ほとんどが交換です。外した錠には、その家の設定や登録が残っています。

  • 外した錠が動くなら、住む人の前で初期化してから持ち帰ります。
  • 動かないなら、封をして持ち帰ります。
  • 新しい錠は、住む人が自分のスマートフォンで登録します。

錠の電池や、ドアホンの線のゆるみは、定期の点検で見つけられます。扉は長く使われるので、納めた扉の数が、これからの仕事の数になります。

住む人が替わる時

家を売る時、貸す時、相続の時には、住む人が替わります。

分かっている事

  • このサイトの扉の決めでは、持ち主が替わる時に、登録先と、その登録先が入れた鍵を全部消し、新しい持ち主が自分の鍵を入れます(戸建てと事務所で、スマートフォンの鍵をどう持つか の「戸建ての扉が、工場から家に届くまで」)。
  • Apple は、対応する錠を全部ホームから外した時に、ホームキーは自動でウォレットから消える、と書いています(会社に情報を集めるから、流出が起こる の「ウォレットの鍵は、どこに何があるか」)。

このサイトの考え

  1. 前の人が、自分のホームから錠を外します。
  2. 錠を初期化して、錠が信じる鍵を空にします。前の人が遠くにいる時や、亡くなっている時は、この手順で前の人の登録を消します。
  3. 錠に誰の登録も無い事を確かめます。
  4. 次の人が、自分のスマートフォンで登録します。

家の持ち主が替わる時に、扉をどう空にするかを知っているのは、扉を納めた人です。建てた会社や工務店に、あらためて声がかかる仕事になります。

今ある家に付ける

ここは、このサイトの考えです。リフォームでは、扉の今の状態で、やり方が分かれます。

[cols="1,2,2"]

やり方 向く家 見る事
錠だけ替える 扉がまだ使え、錠を替えられる作り 電池で動かすか、線を引くか
扉ごと替える 扉が古い、断熱や防犯も直したい 設計の段と同じ。電源、線の通り道、後から錠を替えられるか
電源の線を足す 電池の錠を使っていて、電池切れに困っている 玄関の近くにコンセントがあるか。壁の中の通り道。ドアホンやカメラの線も一緒に考える

どのやり方でも、引き渡しは新しい家と同じ手順です。

現地に行く人と、鍵を登録する人を分ける

ここは、このサイトの考えです。

現地に行く人と、鍵を登録する人は分けます。登録するのは住む人です。現地の人は、自分のスマートフォンで錠を登録したままにしません。

鍵を出す会社の中で、相手を知る所と、鍵を出す所を分ける形は、扉を作る会社が、ウォレットの鍵を出す会社になるには の「会社の形。新しく作るのは二つだけ」に書きました。小さな店では、一人が現地にも行き、登録の手伝いもします。それでも、鍵の登録は住む人がやり、店の人は手を出さない、と決めておけば足ります。試しに登録した時は、その場で初期化します。

記録は、作業の伝票だけを残します。伝票には、いつ、どの家の、どの扉で、何をしたか、外した錠をどうしたかを書きます。住む人の鍵や、家族の名前は書きません。

始めるには

ここは、このサイトの考えです。

  1. 自分の事務所か自宅の扉に、Matter と Aliro の認証を受けた錠を一つ付けます。
  2. スマートフォンは、iPhone と Android の両方を用意します。
  3. 登録、家族への配り方、消し方、初期化を、自分でやってみます。二台のスマートフォンで、住む人が替わる時の手順も試します。
  4. 電池が切れた時と、停電の時に、どう開けるかを試します。
  5. やった事を、自分の店の手順書と、確かめる項目にまとめます。AI は手順書の案を作れますが、それを実機で確かめるのは人です(人に残るのは現場)。

扉と鍵の考え方は、解説 の一覧にまとめています。

分かっていない事

2026年11月15日の時点で、次の事はまだ確かめていません。

  • 日本で売られる Matter と Aliro の錠とドアホンの顔ぶれと、売り出す時期。解説 21 を書いた 2026年11月11日の時点では、日本向けの Aliro に対応した錠の発表は見つかっていませんでした(Google Wallet に戸建ての家の鍵が入る の「日本の読者にとって」)
  • Google Wallet の戸建ての家の鍵を、日本で使えるか
  • 電子錠が、電気工事士法施行令 第1条 第4号の「これらに類する施設」に当たるかどうか。役所に確かめていません
  • 錠を初期化した時に、前の住む人のウォレットに残った鍵がどう扱われるか
  • 錠ごとの初期化のやり方と、登録が空になった事の確かめ方
