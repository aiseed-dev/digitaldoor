宿と貸室で、スマートフォンの鍵をどう渡すか

一度きりの客に、期限つきの鍵を渡す。本人確認、鍵を渡す道、両方が信用できる記録

2026.11.12

ホテル、旅館、簡易宿所、住宅を使った宿泊。貸し会議室や貸しスペースのように、時間や日で貸す部屋。こうした所の鍵は、住宅や事務所の鍵と違います。使う人は一度きりです。期限は時刻で決まります。客にアプリを入れてもらう事は、まずできません。

もう一つ違う事があります。鍵を出す側と使う側の利害が分かれます。留守の間に誰かが入ったか、いつ出たか、借りた時間を超えたか。入った記録が、争いと料金の元になります。

戸建てと事務所の鍵の話は、戸建てと事務所で、スマートフォンの鍵をどう持つかに、会員証の話は、スマートフォンを会員証にするに書きました。この記事では、宿と貸室の鍵の話をします。役所と会社が正式に書いている事と、このサイトの考えは分けて書きます。この記事の内容は、2026年11月12日に確かめた物です。

住宅や事務所と、何が違うか

[cols="2,3,3"]

観点 住宅、事務所 宿、貸室
使う人 家族、社員。同じ人が長く使う 客、借りる人。一度きりか、短い間
期限 無いか、長い 時刻で決まる。泊まる間、借りている時間だけ
アプリ 入れてもらえる 入れてもらえない事が多い
鍵を出す側と使う側 同じか、同じ会社の中 利害が分かれる。入ったか、いつ出たかが、争いと料金の元になる
人の居る受付 ある事が多い 置かない運営が増えている
法令 住宅、事業所の決まり 宿泊には、本人確認と名簿の決まりがある

鍵を出す、止める

ここからは、このサイトの決めです。

宿と貸室の鍵の管理者は、その経営者です。発行者の鍵は、経営者のコンピューターの、取り出せない所に置きます(R-LR-01)。

鍵は予約ごとに出します。一つの鍵は、部屋と、始まりと終わりの日時を持ちます。扉は、自分の時計で期限を確かめます。ネットワークが止まっていても、終わった予約の鍵は通りません(R-LR-02)。

泊まる日を延ばす、早く着く、部屋を替える。どの場合も、新しい鍵を出し、前の鍵を止めます。出した事と止めた事は、台帳に追記で残します(R-LR-03)。

予約を受ける仕組みは、外部のネットワークに向いています。そこで、発行者の鍵と同じサーバーには置きません。同じサーバーに置くと、予約の仕組みを破られたときに、全部の部屋の鍵を作られるからです(R-LR-01)。

客室は、内側から、外からの通常の解錠を拒めるようにします(在室ロック)。内側からは、いつでも機械で開きます(R-LR-05)。

客に鍵を渡す三つの道

客がアプリを入れなくても鍵を受け取れる道を、一つ以上持ちます。どの道を使うかは、経営者が決めます(R-LR-10)。

[cols="2,3,2,3"]

道 客に要る物 強さ 向く場面
ウォレット(Apple、Google)の鍵 スマートフォン。予約の通知からウォレットに入れる 強い。鍵は端末に結ばれ、コピーできない スマートフォンを持つ客。受付を置かない宿
暗証番号 無し。番号を覚えるだけ 弱い。コピーが取れる 貸し会議室、貸しスペース。ウォレットが使えないときの予備
予約の通知から開く一時の鍵 スマートフォンと、通知を開く手段 形による。画面に出すコードはコピーが取れる 短い時間で貸す部屋。ウォレットに入れない客

会社が書いている事

Apple と Google は、ウォレットに入れられる鍵の種類に、ホテルの鍵を挙げています。Apple は Apple Platform Security の「Access key types」の頁で、Google は Google Wallet の Access の一覧で書いています。

ウォレットに鍵を載せるのは、ウォレットの制度に入った会社です。Apple Wallet Access Program のガイドでは、この会社を Credential Manager と呼んでいます。建物を持つか、管理する者は Participating Provider と呼ばれ、Credential Manager を通じて入ります。宿の経営者は、この Participating Provider の立場で入る形です。

このサイトの決め

このサイトの決めでは、ウォレットの鍵は、認証と権限を分ける形で受けます(R-LR-11、R-AC-25)。

  • ウォレットに鍵を載せる会社の署名は、鍵が本物である事の確かめにだけ使います
  • 扉は、経営者の予約の仕組みが登録した鍵だけを、泊まる間、借りている間だけ通します
  • ウォレットに鍵を載せる会社には、誰がどの部屋に入れるかの台帳と、出入りの記録を渡しません

暗証番号と画面に出すコードは、コピーが取れます。使うときは、部屋と期限を限り、使われた事が記録で分かるようにします。端末の鍵に結んだ鍵より弱い事を、経営者が承知して選びます(R-LR-12)。

ウォレットと、ウォレットに鍵を載せる会社の仕組みが止まっても、暗証番号か、受付で開けられるようにします(R-LR-13)。

本人確認が済んだ人にだけ鍵を渡す(宿泊)

役所が書いている事

厚生労働省は、「旅館業における衛生等管理要領」を改正しました。改正日は令和7年3月11日、施行日は令和7年4月1日です。厚生労働省の案内「令和7年4月1日からフロント要件が変わります！」が、改正の中身を説明しています。

玄関帳場(フロント)を置かない場合の条件は、三つです。

  1. 緊急のときの体制。求めに応じて、通常おおむね10分程度で、職員等が駆けつけられる事
  2. 本人確認と、出入りの状況の確認
  3. 鍵の受渡しを、適切に行う事

本人確認と出入りの確認は、二つの形から選べます。

[cols="1,4"]

形 中身
カメラ 営業者が設置したビデオカメラ等で、常時鮮明な画像で行う
ICT と鍵 ICT を使って本人確認を行う。本人確認を受けた者に交付した鍵が無ければ、宿泊者専用区域に出入りできないようにする。出入りの状況を、顔を判別できる角度で録画する

本人確認の方法には、新しい形が加わりました。営業者と宿泊する人が、本人確認に必要な情報(氏名、住所、連絡先など)と、営業者が出す二次元コードや暗証番号などを、事前に共有します。宿泊する人は、それを施設の自動チェックイン機器等で示し、営業者が照合します。その様子は、顔を判別できる角度で録画します。

日本国内に住所の無い外国人の宿泊者には、旅券の呈示を求め、写しを名簿と一緒に保存します。自動チェックイン機器等による電子的な保存も含まれます。

国土交通省の民泊制度ポータルサイトは、住宅を使った宿泊について書いています。宿泊の開始までに、宿泊者それぞれについて本人確認を行います。方法は、対面か、対面と同等の ICT を使う方法です。対面と同等というのは、顔と旅券が画像で鮮明に確認でき、その画像が届出住宅の中か近くなどから発信されていると確認できる事です。例として、テレビ電話やタブレット端末が挙がっています。宿泊者名簿は 3 年間保存します。

このほかに、自治体の条例で条件が加わる事があります。

このサイトの決め

このサイトの決めでは、本人確認が済んだ人にだけ鍵を渡します。その鍵が無ければ、宿泊する人だけが入る区域には入れません。本人確認の記録(いつ、どの方法で行ったか)と、鍵を出した記録は、同じ予約の下に結びます(R-LR-20)。

本人確認と名簿は、経営者の仕組みが受け持ちます。扉と錠は、名簿も旅券の写しも持ちません。扉の記録には、鍵の識別だけを残します(R-LR-21)。名簿と旅券の写しは、気をつけて扱う情報を含むからです。

出入りを録画するカメラは、構内で録画できるようにします。録画と扉の記録を時刻で照らせるように、扉とカメラの時刻を同じ相手に合わせます(R-LR-22)。

記録を、両方が信用できる物にする

宿と貸室では、鍵を出す側と使う側の利害が分かれます。

[cols="1,4"]

場面 争いになる事
宿泊 留守の間に、誰かが入ったか。いつ出たか
貸室 借りた時間を超えたか。使っていない時間に入ったか

ここからは、このサイトの考えです。

出す側だけがとった記録は、使う側から信用されません。出す側は、相手の名前の鍵を、自分で作れるからです。記録が両方に通用するには、次の三つが要ります。会員証の話(スマートフォンを会員証にする)と同じ条件です。

  1. 第三者(ウォレットに鍵を載せる会社)が、鍵が本物である事を保証する
  2. 鍵を、端末の鍵に結ぶ
  3. 扉の記録の鍵を、経営者が取り出せない所に置く

このサイトの決めでは、部屋の出入りは、扉が、連番と連鎖と署名のついた記録として残します。客は、自分が泊まった間、借りていた間の、自分の部屋の記録を見られます(R-LR-30)。

清掃、点検、経営者の側の人の鍵は、部屋と、曜日と時間帯を限ります。客の居る部屋を経営者の側の鍵で開けたときは、客に通知が届き、その記録を客が見られます。緊急のときに入る手順を決め、入った事を記録に残します(R-LR-04)。

時間で貸す部屋

時間で貸す部屋では、終わりの時刻が、次の人の始まりになります。このサイトの決めでは、次のようにします。

  • 予約の始まりの前と、終わりの後は、借りる人の鍵で開きません(R-LR-40)
  • 終わりの時刻に中に人が居ても、内側からは出られます(R-LR-40)
  • 終わりの後に扉が開いたままなら、経営者に知らせます(R-LR-40)
  • 予約と予約の間に、清掃と確かめのための時間を置けます。長さは経営者が決めます(R-LR-41)
  • 料金が時間や回数で決まる所では、入った時刻と出た時刻の記録を、料金の元として書き出せます(R-LR-31)

決まっていない事

2026年11月12日の時点で、次の事は決まっていません。

  • ウォレットのホテルの鍵を、どの会社の仕組みで載せるか。Apple と Google の制度に入った会社が要ります
  • 宿が今使っている予約と受付の仕組みと、鍵の管理のソフトのつなぎ方
  • 緊急のときに経営者の側が入る手順と、客への知らせ方
  • 予約の通知から開く一時の鍵の形と、強さ
