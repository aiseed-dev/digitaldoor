日本のスマートドアとスマートロックの現状

業界団体、通信の規格、制度、各社の窓口、催しを、同じ見方で並べる

2026.10.18

スマートドアとスマートロックを作る人が集まる場所 と同じ見方で、日本の状況を整理します。調べたのは2026年10月17日です。出典は、各団体、官庁、各社の公式の頁と発表を主にし、報道だけで確かめた事柄はそのように書きます。

業界団体

団体 していること スマートロックと公開の仕様
日本ロック工業会 錠メーカーの団体。防犯性能の高い建物部品の官民合同会議の構成団体で、錠、シリンダー、サムターンの試験の窓口 取り組みは見つからない。公式の頁と会員の名簿を見つけられなかった
日本サッシ協会 窓と扉の団体。防犯の委員会を持ち、防犯性能の高い建物部品の扉の区分を扱う。2025年5月に防犯設計のハンドブックを発行 取り組みは見つからない
日本シヤッター・ドア協会 防火シャッターと防火戸の点検の資格者の認定 取り組みは見つからない
日本防犯設備協会 一般向けの「出入口のセキュリティガイド」(2022年)で、電気錠、電気ストライク、スマートフォンによる認証、火災の信号による解錠を解説 ガイドで解説。技術基準に入退室管理や錠の通信の基準は見つからない
エコーネットコンソーシアム 家庭の機器の通信規格 ECHONET Lite 電気錠の機器の種類を定め、仕様を公開
CSA 日本支部 Matter と Aliro。2024年5月に38社で発足、2026年9月の時点で約80社 中心の話題。会員向け(Adopter 以上)

スマートロックを専門に扱う業界団体や協議会は、見つかりませんでした。近い物として、不動産テック協会の不動産オープンID推進部会の資料に、鍵の依頼に触れる記述があります。

防犯性能の高い建物部品(CP部品)

警察庁、国土交通省、経済産業省と民間の16団体が、2002年11月25日に官民合同会議を設けました。侵入までに5分以上かかる建物部品を試験で確かめて目録に載せ、CP マークを付けます。2026年3月末の時点で、17種類、3,545品目です。電気錠も錠の区分に入っています(日本サッシ協会の目録)。

試験は、物理的な攻撃に対する強さを見ます。通信の安全を扱う規定は見つけられませんでした。

通信の規格

規格(決める所) 公開 錠に関わる所
ECHONET Lite(エコーネットコンソーシアム) 仕様は誰でも閲覧できる 電気錠の機器の種類(クラスコード 0x026F)を、Web API の機器仕様(v1.3.0、2021年6月25日)で定めている
JEM-A、JEM1427(日本電機工業会) 公開の本文を見つけられなかった インターホンと電気錠の連動の接点。各社の取扱説明書に、極性、アダプター、配線の長さの制限が書かれている
Matter、Aliro(CSA) 確定した仕様は無料 日本支部が日本語で活動している

ECHONET Lite の電気錠の種類は、日本で公開されている通信の規格のうち、錠を扱う唯一の物でした。JEM-A は建物の現場で広く使われていますが、本文は公開されていません。

制度

JC-STAR

JC-STAR は、IoT 製品のセキュリティの適合ラベルの制度です。経済産業省の監督のもとで IPA が運営し、2025年3月に★1の申請の受付が始まりました。★1は、IoT 製品に共通する最低限の脅威への備えです。

美和ロックは2025年10月7日に、住宅の玄関扉用の電気錠「iEL Zero smart シリーズ」で★1を取得し、錠メーカーとして初めてだと発表しました。IPA の一覧では、ラベルの付与は2025年9月11日、期限は2027年9月10日です。扉の周りでは、パナソニックのドアホン「外でもドアホン」(2026年2月6日)や、Axis の入退室管理とインターホンを含む製品(2025年5月12日)もラベルを受けています。後付けのスマートロックは、確かめた範囲の一覧には見当たりませんでした。

置き配とオートロック

国土交通大臣は2025年9月16日の会見で、宅配の業者がオートロックを自由に開けられる仕組みを国が作るという話は事実ではないと述べました。あわせて、民間の各社が開発した解錠の仕組みが、既に2万棟を超えるマンションに入っていること、配達員の本人確認と解錠の記録、事前に登録した荷物だけの一時的な解錠、管理組合の合意という条件で使われていることを説明しました。令和8年度の予算要求には、配送会社をまたいだ伝票番号と配送データの標準化を支える事業が入っています。

事業者の例として、美和ロックと PacPort は2026年1月13日に、ヤマト運輸の「EAZY」の配達でオートロックを解錠する仕組みを2026年春から始めると発表しました。

火災と避難

建築基準法施行令第125条の2は、屋外への出口などの施錠装置を、屋内から鍵を使わずに開けられる構造にすることを定めています。火災の信号による解錠、非常時の解錠、予備の電源の扱いは、各地の火災予防条例と消防の基準で決まります。例えば名古屋市の「電気錠の指導基準」は、電気錠を通電時に施錠する型など四つの型に分け、避難に要る出入口では、防災センター等からの遠隔の解錠と、自動火災報知設備に連動した解錠を、型に応じて求めています。国としてまとめた電気錠の通知は見つけられませんでした。

経済産業省の「スマートホームの安心・安全に向けたサイバー・フィジカル・セキュリティ対策ガイドライン」(2021年4月)は、スマートホーム全体を扱い、錠に絞った章はありません。

開発者の窓口は、個人でも使える公開の物(SESAME、SwitchBot)と、営業を通す物(Akerun 等)に分かれています。

開発者の集まり

Qiita と Zenn には、SESAME や SwitchBot の API で錠を動かす記事が多くあります。例は、SESAME3 を Web API で動かす記事(2021年8月)や、SwitchBot の API v1.1 で錠を遠隔操作する記事(2022年9月)です。フォトシンスは2017年に Akerun の Advent Calendar を開きました。こうした記事の多くは2019年から2023年のものです。

connpass では、Matter の勉強会が数件(2023年7月、2024年5月)見つかりました。スマートロックや Aliro の集まりは見つかりませんでした。

足りない物

  1. スマートロックを扱う業界団体。 錠の業界団体は物理の防犯の試験の窓口で、公開の仕様は見当たりません。
  2. 扉、錠、業務システムの間の公開の接続仕様。 ECHONET Lite の電気錠の種類と、始まったばかりの Matter と Aliro だけです。建物の現場で使われる JEM-A は本文が公開されていません。
  3. 火災と避難のときの電気錠の挙動の、全国で同じ前提。 決まりは各地の基準にあり、国としてまとめた公開の文書は見つかりません。扉のコントローラを作る人が、全国で同じ前提を持てません。
  4. 事業者が公開の条件で使える開発者の窓口。 個人向けと営業経由に分かれています。
  5. 業界と開発者が会員制でなく会う場。 両者が同じ場にいるのは CSA 日本支部で、Adopter(年7,500ドル)以上の会員制です。
  6. 置き配の解錠の条件を確かめる公開の試験。 2万棟を超える建物で動いていますが、本人確認、解錠の記録、管理組合の合意という条件を確かめる公開の仕様と試験は見つけられませんでした。

このサイトの 扉のコントローラの仕様 は、3 と 6 にある火災と停電のときの挙動と、改ざんの分かる解錠の記録を、番号の付いた要求と公開のテストで扱っています。
