= 情報サイト「デジタルドア」を開設しました

電子錠、ドアホン、扉のコントローラ、鍵の発行、通信規格(Aliro、Matter)など、扉と鍵に関する技術情報を解説するサイトを開設しました。

扉に関する情報は、錠メーカー、ドアホンメーカー、規格団体がそれぞれの立場で発信しており、扉を使う側の視点で全体を見渡した解説はあまりありません。このサイトでは、玄関まわりの技術を、扉の製造、電子錠、コントローラ、ドアホン、スマートフォン、周辺機器、通信規格、鍵の発行、業務システムとの連携、という層に分けて整理し、各層の役割と責任の所在を解説していきます。

== コンテンツ

* 解説記事。通信規格と機器の基礎知識を扱います。最初の三本は、link:/guide/matter/[Matterとは何か]、link:/guide/aliro/[Aliroとは何か]、link:/guide/what-a-smart-door-needs/[スマートドアに求められる条件]です。
* ブログ。お知らせと、時事的な話題に関するノートを掲載します。
* ニュース。AIが関連ニュースを収集して一行に要約し、発表・報道・噂・解説の種別を付けます。掲載する記事は編集者が選びます。

endif::[]
